1. Where the course left off

We already know the trivial derandomization \(\BPP \subseteq \EXP\): run the machine on every possible random string and take the majority answer 455-PTC2 p.2. If a machine uses only \(p(n) = O(\log n)\) random bits, the same enumeration takes \(2^{O(\log n)}\cdot\poly(n) = \poly(n)\) time. So to prove \(\Pclass = \BPP\), it suffices to convert every polynomial-time probabilistic TM with bounded error into one that still runs in polynomial time with bounded error but uses only \(O(\log n)\) random bits 455-PTC2 p.2.

The lecture's plan is a pseudorandom generator (PRG): a TM \(G\) that turns \(O(\log n)\) truly random seed bits into \(\poly(n)\) bits that “look random” to (“fool”) poly-time machines. The new machine is \(M'(x,s) = M(x, G(s))\) 455-PTC2 p.2–3. The deterministic simulation then works like this:

  • Run \(M'(x,s)\) for every seed \(s\). There are only \(2^{O(\log n)} = \poly(n)\) of them.
  • Output the majority answer.

The answers need not agree across seeds. Even with truly random bits, \(M\) is wrong on up to \(1/3\) of random strings. What “fooling \(M\)” guarantees is that the fraction of seeds giving the right answer is close to the fraction of truly random strings giving the right answer (at least \(2/3\)). So more than half the seeds are right, and the majority vote is correct. If the fraction under \(G\) were far from what random bits give, then “run \(M(x,\cdot)\) and check the answer” would itself be a test that tells \(G\)'s output apart from random. Section 8 turns this into a proof V Thm. 7.5, p.143.

The course then says we believe such PRGs exist because hard functions can be turned into pseudorandomness (“Hardness ⟹ Derandomization”), but gives no definitions or proofs 455-PTC2 p.3. The slogan is “randomness is in the eye of the beholder” 455-PTC2 p.3. (The lecture also states a converse, “Derandomization ⟹ Hardness”: putting PIT in P would give circuit lower bounds 455-PTC2 p.7. We don't prove or use it; it's mentioned once more in Section 8 for completeness.)

This page makes the sketch precise. It answers four questions:

  1. What exactly does “looks random to poly-time machines” mean?
  2. What exactly is a “hard function”? (One-way functions: on the Section 2 page.)
  3. What proof techniques let us use these definitions? (Reductions and hybrid arguments.)
  4. What is the exact derandomization theorem, with exact parameters?

2. Formal setup

2.1 How small is “effectively zero”? Negligible functions

Every security statement on this site says that some adversary's advantage (its edge over blind guessing, made precise in Section 3) is tiny. Advantages are functions of a size parameter \(n\) (Section 2.2), so we need a precise meaning for “tiny as a function of \(n\)”. Two requirements pin it down Claude: this framing:

  1. Repetition shouldn't help. An efficient adversary can rerun its attack \(\poly(n)\) times. If one run has advantage \(\varepsilon(n)\), many runs together have advantage roughly up to \(p(n)\cdot\varepsilon(n)\). “Tiny” must survive that.
  2. Reductions lose polynomial factors. The hybrid argument (Section 6) gives equations like \(\mathrm{Adv}[A] = n\cdot\mathrm{Adv}[B]\). If \(\mathrm{Adv}[B]\) is tiny, we need \(n\cdot\mathrm{Adv}[B]\) to be tiny too.

So the class of “tiny” functions must be closed under multiplication by any polynomial.

Inverse polynomials fail this test. \(1/n^{5}\) looks small, but \(n^5\cdot\frac1{n^5}=1\). This is also the boosting phenomenon from class: an advantage of \(1/\poly(n)\) can be amplified to a constant by polynomially many repetitions MIT p.16-3 455-PTC2 p.4–5.

The natural fix is to require \(\varepsilon\) to shrink faster than every inverse polynomial. In big-O language, all of the following say the same thing:

  • \(\varepsilon(n) = O(1/n^c)\) for every constant \(c\).
  • \(p(n)\cdot\varepsilon(n)\to 0\) for every polynomial \(p\).
  • \(\varepsilon(n)=1/s(n)\) for some \(s\) that grows faster than every polynomial (“superpolynomial”), e.g. \(s = 2^n,\ 2^{\sqrt n},\ n^{\log n}\).

Such \(\varepsilon\) are called negligible. Examples: \(2^{-n}\), \(2^{-\sqrt n}\), \(n^{-\log n}\) are negligible. \(1/n^{100}\) and \(1/(1000n^4)\) are not BS Ex. 2.10, p.28.

Definition (negligible), formally
\(\varepsilon:\mathbb{Z}_{\ge 1}\to\mathbb{R}\) is negligible if for every \(c\gt 0\) there is an \(n_0\) with \(|\varepsilon(n)| \lt 1/n^c\) for all \(n\ge n_0\). Equivalently, \(\lim_{n\to\infty} \varepsilon(n)\,n^c = 0\) for every \(c\gt 0\). BS Def. 2.5 & Thm. 2.11, p.28. A function \(s\) is super-poly if \(1/s\) is negligible BS Def. 2.6, p.28.
Closure facts
If \(\varepsilon,\varepsilon'\) are negligible and \(p\) is polynomially bounded, then \(\varepsilon+\varepsilon'\) and \(p\cdot\varepsilon\) are negligible BS Fact 2.6, p.18.
Proof of the second fact.

Approach. Direct, straight from the definition of negligible.

Assume. \(\varepsilon\) is negligible, and \(p\) is polynomially bounded: there is a constant \(k\) with \(p(n)\le n^k\) for all large \(n\).

Recall. \(\varepsilon\) negligible means: for every constant \(c\), eventually \(|\varepsilon(n)|\lt 1/n^c\).

WTS: for every constant \(c\), \(p(n)\varepsilon(n)\lt 1/n^c\) for all large \(n\).

Claude Say \(p(n)\le n^k\) for large \(n\). Given \(c\), apply negligibility with \(c+k\): for large \(n\), \(\varepsilon(n)\lt 1/n^{c+k}\), so \(p(n)\varepsilon(n)\lt n^k/n^{c+k}=1/n^c\). ∎

The negation. “Not negligible” means: there is a constant \(c\) with \(\varepsilon(n)\ge 1/n^c\) for infinitely many \(n\). It does not have to hold for all \(n\) BS p.63. When we say an adversary “breaks” a scheme, we mean its advantage is not negligible.

2.2 The security parameter

On this site the security parameter \(n\) is simply the length of the secret input, the part the adversary never sees. For a PRG it's the seed length (and for the one-way functions of the Section 2 page, it will be the input length \(|x|\)) HILL §3.1, p.1371. When a construction also has public random inputs, \(n\) counts only the secret part. For example, in Goldreich–Levin (Section 2 of the site) the string \(r\) is public HILL p.1371.

Why the exact choice doesn't matter: if two candidate parameters are polynomially related (say \(n\) and \(n^2\)), then a function is negligible in one exactly when it is negligible in the other Claude.

2.3 Who are the adversaries? Uniform vs. nonuniform

There are two standard choices, and the difference matters in Section 8.

  • Uniform: “efficient adversary” = probabilistic polynomial-time algorithm (PPT). Boneh–Shoup use this BS §2.3, p.28, and so do HILL and the MIT notes.
  • Nonuniform: “efficient adversary” = a family of polynomial-size circuits, i.e. a \(\Ppoly\) machine. Vadhan uses this throughout V §7.1.1, p.141.

We know the circuit side from class: \(\Ppoly = \bigcup_k \mathsf{SIZE}(n^k)\), \(\Pclass \subseteq \Ppoly\), circuits can hard-code advice, and \(\BPP\subseteq\Ppoly\) by fixing a good random string for each input length 455-BC1 455-BC2. Consequences:

  • Randomness doesn't help a circuit adversary. Fix its coins to the best choice and hard-code them; the advantage doesn't drop V p.141–142. This is the same trick as \(\BPP\subseteq\Ppoly\).
  • Nonuniform adversaries are more powerful. So “secure against all poly-size circuits” is a stronger assumption than “secure against all PPTs”, and also a stronger conclusion. Section 8 needs the stronger kind, because its proof hard-codes the BPP input \(x\) into the distinguisher V Claim 7.6, p.143.
  • Why proofs are often easier in the nonuniform setting. Claude, illustrated by V p.149 BS p.63. A security proof is a reduction: given an adversary \(A\) against the construction, we must build an adversary \(B\) against the assumption, in the same model.
    • If \(B\) may be a circuit, it can hard-code anything useful: the best hybrid index, the best coin flips, the best fixed values for the other inputs. We only need to show such good values exist, usually by averaging.
    • If \(B\) must be a uniform PPT, it has to compute or sample everything itself. That forces tricks like picking the hybrid index at random (Section 6) and requires the distributions to be efficiently samplable.
    So the more powerful model makes the reduction's job easier. Neither statement (“circuit-secure ⇒ circuit-secure” or “PPT-secure ⇒ PPT-secure”) implies the other, because both the hypothesis and the conclusion change.

2.4 Conventions used on this page

We use Boneh–Shoup's convention throughout. Advantage is a difference of probabilities, written \(\mathrm{PRGadv}[A,G]\), \(\mathrm{Distadv}[A,P_0,P_1]\), and so on. “Secure” means the advantage is negligible for every efficient adversary. When a reduction gives an exact relation, such as \(\mathrm{PRGadv}[A,G']=n\cdot\mathrm{PRGadv}[B,G]\), we record it, because it shows how much security is lost BS Thm. 3.2, p.55. Section 8 introduces one restricted variant of the PRG game when derandomization needs it.

One formula for distinguishing. Every distinguishing game on this site, in this section and the next ones, uses the two-experiment formula \(\Pr[W_0]-\Pr[W_1]\). (Boneh–Shoup also define an equivalent “bit-guessing” formulation BS §2.2.5. We don't use it.) The only other kind of game is a prediction game (Section 7, and Goldreich–Levin later). There the adversary predicts a bit of data, and we always write its success probability as \(\frac12+\varepsilon\) and call \(\varepsilon\) its prediction advantage. In both kinds of game, “secure” means the advantage is negligible. In a prediction game it is the success probability, not the advantage, that sits near \(\frac12\).

3. Indistinguishability and the attack-game style

3.1 Attack games

Boneh–Shoup phrase every security definition as an attack game between two parties BS §2.2.2, p.15–16:

  • a challenger, who follows a fixed, simple procedure; and
  • an adversary \(A\), who may use any efficient strategy at all.

Most games have two experiments, numbered 0 and 1. The adversary behaves the same way in both, but the challenger does something different. At the end the adversary outputs a bit \(\hat b\). Let \(W_b\) be the event “\(A\) outputs 1 in Experiment \(b\)”. Then

$$\text{advantage} = \big|\Pr[W_0]-\Pr[W_1]\big|.$$

Advantage measures how differently \(A\) behaves in the two worlds. It is not \(A\)'s success probability. An adversary that always outputs 1 has \(\Pr[W_0]=\Pr[W_1]=1\) and advantage 0: it learned nothing.

The basic game, of which every other game on this site is a special case:

Figure 1. The distinguishing game for distributions \(P_0,P_1\) on a finite set \(R\). Modeled on BS Fig. 2.1, p.16; Attack Game 3.3, p.82.

Attack Game (distinguishing \(P_0\) from \(P_1\))
In Experiment \(b\in\{0,1\}\), the challenger samples \(x\leftarrow P_b\) and sends \(x\) to \(A\). Then \(A\) outputs \(\hat b\in\{0,1\}\). $$\mathrm{Distadv}[A,P_0,P_1] := \big|\Pr[W_0]-\Pr[W_1]\big|.$$ BS Attack Game 3.3, p.82

Dropping the absolute value. In proofs we usually assume \(\Pr[W_0]-\Pr[W_1] \gt \varepsilon\) without the absolute value. If the difference is negative, flip \(A\)'s output bit, which costs nothing V proof of Prop. 7.14, p.149.

3.2 The best any adversary could ever do: statistical distance

Before restricting to efficient adversaries, ask: if the adversary had unlimited computing power, what is the largest advantage it could get in Figure 1? The answer is a single number depending only on \(P_0\) and \(P_1\). It measures how distinguishable the two distributions are in the ideal case, where computation is free.

Finding the best adversary. Assume \(A\) is deterministic; we'll see randomness doesn't help. Then \(A\) is just a rule “output 1 if \(x\in R'\)” for some set \(R'\subseteq R\), and

$$\Pr[W_0]-\Pr[W_1] = P_0[R']-P_1[R'] = \sum_{r\in R'}\big(P_0(r)-P_1(r)\big).$$

To make this as large as possible, put every \(r\) with \(P_0(r)\gt P_1(r)\) into \(R'\), since each adds a positive amount, and leave out every \(r\) with \(P_0(r)\lt P_1(r)\). In words: the best unbounded adversary answers “Experiment 0” exactly when the sample it sees is more likely under \(P_0\) than under \(P_1\). Its advantage is

$$\sum_{r:\,P_0(r)\gt P_1(r)}\big(P_0(r)-P_1(r)\big) \;=\; \tfrac12\sum_{r\in R}\big|P_0(r)-P_1(r)\big|.$$

The equality holds because both distributions sum to 1. So the total amount by which \(P_0\) exceeds \(P_1\) equals the total amount by which \(P_1\) exceeds \(P_0\), and each is half the sum of all the gaps BS proof of Thm. 3.10, p.83–84. A randomized adversary is an average of deterministic ones, so it can't do better than the best of them BS proof of Thm. 3.11, p.84.

Definition (statistical distance)
$$\Delta[P_0,P_1] := \tfrac12\sum_{r\in R}|P_0(r)-P_1(r)| \;=\; \max_{R'\subseteq R}\big|P_0[R']-P_1[R']\big|.$$ By the argument above, this is exactly the best advantage any adversary, efficient or not, can achieve in the distinguishing game. BS Def. 3.5 & Thm. 3.10, p.83 V Def. 6.2, p.111

Examples.

  • A fair coin vs. a slightly biased coin. Claude Let \(P_0\) be a fair bit and \(P_1\) a bit with \(\Pr[1]=\frac12+\delta\). Then \(\Delta=\frac12(\delta+\delta)=\delta\). The best adversary says “Experiment 0” on seeing a 0.
  • Uniform on \(\{1,\dots,m\}\) vs. uniform on \(\{1,\dots,m-\delta\}\). \(\Delta=\delta/m\) BS Ex. 3.1, p.83.
  • A PRG's output vs. truly random. Claude; the same counting as V p.140. Let \(P_0\) be the distribution of \(G(s)\) for a uniform seed \(s\in\bits^\ell\), and \(P_1\) uniform on \(\bits^L\) with \(L\gt\ell\). Take \(R'=\mathrm{Im}(G)\), the set of possible outputs. Then \(P_0[R']=1\), but \(|R'|\le 2^\ell\), so \(P_1[R']\le 2^{\ell-L}\). Hence \(\Delta\ge 1-2^{\ell-L}\ge \frac12\). Statistically, a PRG's output is nowhere near uniform: an all-powerful adversary just checks whether the string could have come out of \(G\). Pseudorandomness only makes sense because that check is too expensive for an efficient adversary. This is the formal version of “randomness is in the eye of the beholder”.

One consequence of the “best adversary” view: applying any function \(f\) to the sample can't increase \(\Delta\), i.e. \(\Delta(f(X),f(Y))\le\Delta(X,Y)\). An adversary that first computes \(f\) and then tests is just another adversary V Lemma 6.3(5), p.112.

3.3 Computational indistinguishability

Now restrict the adversary to be efficient.

Definition (computational indistinguishability)
\(P_0\) and \(P_1\) (really, families indexed by \(n\)) are computationally indistinguishable if \(\mathrm{Distadv}[A,P_0,P_1]\) is negligible for every efficient adversary \(A\). BS Def. 3.4, p.82 V Def. 7.1–7.2, p.141–142 HILL Def. 3.3, p.1372
Theorem (statistical ⇒ computational)
For every adversary \(A\), \(\mathrm{Distadv}[A,P_0,P_1]\le\Delta[P_0,P_1]\). So if \(\Delta\) is negligible, \(P_0\) and \(P_1\) are computationally indistinguishable. BS Thm. 3.11, p.84
Proof.

Approach. Direct: compare \(A\) with the best possible adversary.

Assume. \(P_0,P_1\) are distributions on a finite set \(R\), and \(A\) is any adversary (efficient or not).

Recall. Section 3.2: \(\Delta[P_0,P_1]\) equals the largest advantage any adversary can get in the distinguishing game.

WTS: \(\mathrm{Distadv}[A,P_0,P_1]\le\Delta[P_0,P_1]\).

\(\Delta\) is the best advantage over all adversaries (Section 3.2). Efficient adversaries are some of those, so none of them can beat it. ∎

The converse is false, and the third example above shows the gap. \(G(U_\ell)\) vs. \(U_L\) has \(\Delta\ge 1/2\), yet the two can still be computationally indistinguishable. That gap is exactly the space PRGs live in.

4. Pseudorandom generators

4.1 Definition and examples

A PRG is an efficient deterministic algorithm \(G:\bits^\ell\to\bits^L\) with \(L\gt\ell\). Its security is the distinguishing game with \(P_0 = G(\text{uniform seed})\) and \(P_1 = \) uniform:

Figure 2. The PRG attack game. Modeled on BS Fig. 3.1, Attack Game 3.1, p.46–47.

Definition (secure PRG)
\(\mathrm{PRGadv}[A,G] := |\Pr[W_0]-\Pr[W_1]|\) in the game of Figure 2. \(G\) is secure if \(\mathrm{PRGadv}[A,G]\) is negligible for every efficient \(A\). Equivalently, \(G(U_\ell)\) and \(U_L\) are computationally indistinguishable. BS Def. 3.1, p.47; p.82 HILL Def. 3.5, p.1373 MIT p.16-3

Worked examples: breaking bad PRGs. Claude: these specific generators. The style follows BS's statistical-test examples BS p.46. Each row is an adversary playing the game in Figure 2.

Notice what breaking required in each case: one efficient test whose acceptance probability differs noticeably between the two worlds. Security requires that no such test exists, among all efficient tests at once.

One bit of stretch suffices. The definition only asks for \(L\ge\ell+1\). Any PRG with 1 bit of stretch can be extended to any polynomial stretch HILL Prop. 3.6, p.1373 BS §3.4.2, p.59. This is proved in Section 6.

4.2 Why this definition, and not something simpler?

Two simpler-sounding definitions come to mind. Both fail.

  1. “\(G\)'s output should be distributed (almost) uniformly.” Impossible. By the third example in Section 3.2, \(G(U_\ell)\) has statistical distance at least \(1/2\) from uniform: it can take at most \(2^\ell\) of the \(2^L\) possible values V p.140.
  2. “\(G\)'s output should pass a standard list of statistical tests” (balanced 0s and 1s, balanced pairs, χ², …). Not enough. There are generators that pass all such standard tests yet are completely predictable: from a prefix of the output you can compute the rest. The linear congruential generator, the default random-number generator in many programming languages, is the classic example BS p.46 V p.142 MIT p.16-2. A fixed list of tests says nothing about the test an adversary designs specifically against \(G\).

Our definition sits between these two. It quantifies over every test, like (1), but only efficient ones, which makes it achievable.

5. Proof strategy 1: reductions

Almost every theorem in this area has the form “if primitive \(P\) is secure, then construction \(C\) is secure.” It is proved by reduction, usually in the contrapositive: given any efficient adversary \(A\) that breaks \(C\), build an efficient adversary \(B\) that breaks \(P\). Usually \(B\) runs \(A\) as a subroutine and plays the challenger for \(A\) BS p.52. Boneh–Shoup call such a \(B\) an elementary wrapper around \(A\). If \(A\) is efficient then so is \(B\), and wrappers compose BS p.20, p.34. The idea is the same as NP-completeness reductions, except that we must also track probabilities and keep \(B\) efficient V p.148.

Figure 3. A reduction. \(B\) attacks primitive \(P\) by running \(A\) (which attacks construction \(C\)) on a game built from \(P\)'s challenge \(z\). If \(b=0\) makes \(A\) see the real \(C\)-game and \(b=1\) makes it see an “easy” game, then \(B\)'s advantage equals the difference between the two. Modeled on BS Fig. 3.4 and p.52.

The template, from the stream-cipher proof BS §3.2, p.49–52:

  1. Start with the real game. Modify it into a game where \(A\)'s advantage is easy to compute (often 0).
  2. Show the two games differ by only a negligible amount. To do this, exhibit a \(B\) whose advantage against \(P\) equals that difference.
  3. Conclude \(A\)'s real advantage is at most (easy advantage) + (negligible).

A short, complete example follows; it uses only the definitions. (A second example, PRG ⇒ one-way function, is on the Section 2 page.)

Theorem 5.1 (PRGs ⇒ P ≠ NP)
If a secure PRG exists (against uniform adversaries), then \(\Pclass\ne\NP\). If one exists against nonuniform adversaries, then \(\NP\not\subseteq\Ppoly\).
V p.145 & Problem 7.3(2), p.178 (stated as an exercise). Proof: Claude
Proof (an adversary in the game of Figure 2).

Approach. Contrapositive. Assuming \(\Pclass=\NP\), we build one efficient adversary (the image test) that breaks any candidate PRG.

Assume. (Contrapositive) \(\Pclass=\NP\); for the circuit version, \(\NP\subseteq\Ppoly\). Let \(G:\bits^n\to\bits^\ell\) with \(\ell\gt n\) be any poly-time candidate PRG.

Recall. A PRG is secure iff every efficient adversary has negligible advantage (Section 4.1). \(\NP\) is the class of languages with certificates checkable in polynomial time. \(G\) has at most \(2^n\) outputs.

WTS: an efficient adversary \(B\) with non-negligible \(\mathrm{PRGadv}[B,G]\). Then no secure PRG exists, which is the contrapositive of the theorem.

Let \(G:\bits^n\to\bits^{\ell}\) with \(\ell\gt n\). Let \(L=\{y:\ y=G(s)\text{ for some } s\}\), the set of strings \(G\) can output. \(L\in\NP\): the seed \(s\) is a certificate, checked by computing \(G(s)\). Suppose \(\Pclass=\NP\), and let \(D\) be a poly-time decider for \(L\).

Adversary \(B(r)\): output 1 iff \(D(r)\) accepts. In words, “say pseudorandom iff \(r\) is something \(G\) could have produced.”

  • Experiment 0 (\(r=G(s)\), uniform seed \(s\)): \(r\in L\) always, so \(\Pr[W_0]=1\).
  • Experiment 1 (\(r\) uniform in \(\bits^\ell\)): \(B\) outputs 1 only if \(r\in L\). Since \(G\) has only \(2^n\) seeds, \(\Pr[W_1]\le 2^n/2^\ell\le 1/2\).

Advantage: \(\mathrm{PRGadv}[B,G]=\Pr[W_0]-\Pr[W_1]=1-\frac{|\mathrm{Im}(G)|}{2^\ell}\ge 1-2^{n-\ell}\ge\frac12\) for every \(n\), and \(B\) is efficient because \(D\) is.

Why this is not negligible: take \(c=1\) in the definition. A negligible function would be \(\lt 1/n\) for all large \(n\), but \(\mathrm{PRGadv}[B,G]\ge 1/2\ge 1/n\) for every \(n\ge 2\). So \(G\) is not secure. The value \(1/2\) is not a threshold in the definition; any non-negligible advantage breaks \(G\), and this one happens to be a constant. Contrapositive: a secure PRG implies \(\Pclass\ne\NP\). Replacing \(D\) by a polynomial-size circuit family deciding \(L\) gives the \(\Ppoly\) version. This is the same image test as the Fact in Section 8.4; here \(\Pclass=\NP\) makes it efficient instead of a short seed. ∎

This explains why nobody can prove that PRGs exist outright (or the one-way functions of the Section 2 page): doing so would separate \(\Pclass\) from \(\NP\). Everything in this area is conditional. The best hope is to reduce one assumption to another, and HILL does exactly that V p.145.

6. Proof strategy 2: the hybrid argument

Often the two extreme distributions (fully pseudorandom vs. fully random) differ in many places at once. A hybrid argument interpolates between them one step at a time. If the extremes are distinguishable, some adjacent pair must be, and an adjacent pair differs in just one place, which a reduction can exploit.

Hybrid lemma (the core inequality)
Let \(H_0,\dots,H_k\) be distributions and \(T\) a test. Then $$\Pr[T(H_0)=1]-\Pr[T(H_k)=1] = \sum_{i=1}^{k}\big(\Pr[T(H_{i-1})=1]-\Pr[T(H_i)=1]\big),$$ so if the left side exceeds \(k\varepsilon\), some term exceeds \(\varepsilon\). V proof of Prop. 7.14, p.149 BS proof of Thm. 3.2, p.56–59

6.1 Example: multiple samples / parallel composition

Theorem 6.1
If \(G\) is a secure PRG, then the parallel composition \(G'(s_1,\dots,s_k)=(G(s_1),\dots,G(s_k))\) is a secure PRG, and for every adversary \(A\) there is an adversary \(B\) with \(\mathrm{PRGadv}[A,G'] = k\cdot\mathrm{PRGadv}[B,G]\) BS Thm. 3.2, p.55. More generally, if \(X,Y\) are computationally indistinguishable, so are \(k\) independent copies \(X^k, Y^k\), with the advantage growing by at most a factor \(k\) V Prop. 7.14, p.148.

Figure 4. Hybrids for \(k=4\). Each step changes exactly one block, so an adversary that notices a step yields an adversary against a single copy of \(G\). Claude: figure, following V p.149 \((H_i = X^{k-i}Y^i)\).

Proof (nonuniform version, following V p.149).

Approach. Contrapositive via a hybrid argument and a security reduction (nonuniform version: we fix the best hybrid index).

Assume. \(A\) is an efficient adversary against \(G'\) with advantage \(\delta=\mathrm{PRGadv}[A,G']\).

Recall. The hybrid lemma (telescoping sum). Averaging: some fixed value of a random variable does at least as well as the average. Circuits may hard-code values for free (Section 2.3). The closure facts (Section 2.1).

WTS: an efficient \(B\) against \(G\) with \(\mathrm{PRGadv}[B,G]\ge\delta/k\). Then if \(G\) is secure, \(\delta\le k\cdot\mathrm{negl}\) is negligible, so \(G'\) is secure.

Write \(X=G(U_\ell)\) and \(Y=U_L\), and let \(H_i = X^{k-i}Y^{i}\) as in Figure 4, so \(H_0\) is \(G'\)'s output and \(H_k\) is uniform. Let \(p_i=\Pr[A(H_i)=1]\). If \(\mathrm{PRGadv}[A,G']=p_0-p_k \gt k\varepsilon\), then by the hybrid lemma some step has \(p_{i-1}-p_i\gt\varepsilon\). Hybrids \(i-1\) and \(i\) differ only in block \(k-i+1\), which is \(X\) in one and \(Y\) in the other. By averaging, there is a fixed choice of the other \(k-1\) blocks for which the gap is still \(\gt\varepsilon\). Hard-code \(i\) and those blocks into \(B(z)=A(x_1..x_{k-i},\,z,\,y_{k-i+2}..y_k)\). This is a circuit of essentially the same size with \(\mathrm{PRGadv}[B,G]\gt\varepsilon\).

Advantage: taking \(\varepsilon\) just below \(\mathrm{PRGadv}[A,G']/k\), we get \(\mathrm{PRGadv}[B,G]\ge \frac1k\,\mathrm{PRGadv}[A,G']\), i.e. \(\mathrm{PRGadv}[A,G']\le k\cdot\mathrm{PRGadv}[B,G]\). (Boneh–Shoup's uniform \(B\) gets exactly \(=\).)

Why this is negligible: \(G\) is secure and \(B\) is efficient, so \(\mathrm{PRGadv}[B,G]\) is negligible. \(k\) is polynomially bounded, so \(k\cdot\mathrm{PRGadv}[B,G]\) is negligible by the closure fact of Section 2.1 BS Fact 2.6. Hence \(\mathrm{PRGadv}[A,G']\) is negligible for every efficient \(A\), and \(G'\) is secure. ∎

The uniform version needs a trick. A uniform adversary can't “hard-code the right \(i\)”, because which \(i\) works may change with \(n\). Boneh–Shoup instead build a single adversary \(B\) that picks \(i\) at random and samples the other coordinates itself (it can, because \(G\) is efficient). Averaging over \(i\), the telescoping sum gives \(\mathrm{PRGadv}[B,G]=\frac1n|p_n-p_0|\) exactly BS p.56–59. Boneh–Shoup also explain why the tempting alternative fails for non-constant \(n\): “one of \(B_1,\dots,B_n\) must work” doesn't give a single fixed machine BS p.63. Vadhan notes that the uniform version requires \(X\) and \(Y\) to be efficiently samplable V p.149. Takeaway: in the uniform setting, “pick the hybrid index at random” is the standard move. In the nonuniform setting you may simply fix the best index.

6.2 Example: stretching a PRG (sequential / Blum–Micali composition)

Theorem 6.2
Let \(G:S\to R\times S\) be a secure PRG. Define \(G'(s)\): set \(s_0=s\); for \(i=1..n\), set \((r_i,s_i)\leftarrow G(s_{i-1})\); output \((r_1,\dots,r_n,s_n)\). Then \(G'\) is secure, with \(\mathrm{PRGadv}[A,G']=n\cdot\mathrm{PRGadv}[B,G]\).
In particular, a PRG \(\bits^\ell\to\bits^{\ell+1}\) gives a PRG \(\bits^\ell\to\bits^{\ell+n}\) for any polynomial \(n\). BS §3.4.2, Thm. 3.3, p.59 HILL Prop. 3.6, p.1373 MIT p.16-3
Proof sketch.

Approach. Hybrid argument, uniform version: the reduction picks the hybrid index at random.

Assume. \(G:S\to R\times S\) is a secure PRG, and \(A\) is any efficient adversary against the \(n\)-wise sequential composition \(G'\).

Recall. The hybrid lemma. Choosing the index uniformly makes \(B\)'s advantage the average of the adjacent gaps (Section 6.1). The closure facts.

WTS: an efficient \(B\) with \(\mathrm{PRGadv}[A,G']=n\cdot\mathrm{PRGadv}[B,G]\), and hence that \(G'\) is secure.

Hybrid \(j\): the first \(j\) blocks \(r_1..r_j\) are uniform, \(s_j\) is a fresh uniform seed, and the rest is computed honestly from \(s_j\). Hybrid 0 is the real \(G'\). Hybrid \(n\) is fully uniform. Hybrids \(j\) and \(j+1\) differ only in whether \((r_{j+1},s_{j+1})\) is \(G(\text{uniform seed})\) or uniform. A PRG adversary \(B\) for \(G\) receives a challenge \(z\), picks \(j\) at random, fills in uniform blocks before position \(j+1\), puts \(z\) at position \(j+1\), computes the rest honestly from \(z\)'s seed part, and runs \(A\). Telescoping as in 6.1 gives the factor \(n\) BS p.60–61.

Advantage: \(\mathrm{PRGadv}[A,G']=n\cdot\mathrm{PRGadv}[B,G]\).

Why this is negligible: \(\mathrm{PRGadv}[B,G]\) is negligible because \(G\) is secure. \(n\) is polynomially bounded, so the product is negligible by the closure fact. ∎

This is the result that justifies “1 bit of stretch is enough”. Section 2 of the site builds a 1-bit-stretch PRG and relies on this theorem for the rest.

7. Next-bit unpredictability (Yao)

A seemingly weaker property: given the first \(i\) bits of the output, no efficient algorithm can predict bit \(i+1\) noticeably better than a coin flip.

Note: this is a prediction game, not a two-experiment game: there is only one experiment, and the adversary tries to predict a bit of \(G\)'s output. Its success probability is \(\frac12+\varepsilon\), and \(\varepsilon\) is the prediction advantage (Section 2.4). Theorem 7.1 is exactly the bridge between this game and the two-experiment PRG game.

Definition (unpredictable PRG)
Attack Game: the adversary picks an index \(i\). The challenger samples \(s\), computes \(r=G(s)\), and sends \(r[0..i-1]\). The adversary outputs a guess \(g\) and wins if \(g=r[i]\). \(\mathrm{Predadv}[A,G]=|\Pr[\text{win}]-1/2|\). \(G\) is unpredictable if this is negligible for all efficient \(A\). BS Attack Game 3.2 & Def. 3.3, p.64 V Def. 7.15, p.150
Theorem 7.1 (Yao: pseudorandom ⇔ next-bit unpredictable)
(a) Secure ⇒ unpredictable, with \(\mathrm{Predadv}[A,G]=\mathrm{PRGadv}[B,G]\).
(b) Unpredictable ⇒ secure, with \(\mathrm{PRGadv}[A,G]=L\cdot\mathrm{Predadv}[B,G]\), where \(L\) is the output length. BS Thm. 3.4, p.64 and Thm. 3.6, p.67 V Prop. 7.16, p.150
Proof of (a).

Approach. Security reduction: turn a predictor into a distinguisher.

Assume. \(A\) is a predictor that chooses index \(i\) and guesses bit \(i\) correctly with probability \(\frac12+\varepsilon\).

Recall. In Experiment 1 the string is uniform, so bit \(i\) is a fresh coin, independent of the first \(i\) bits.

WTS: a distinguisher \(B\) with \(\mathrm{PRGadv}[B,G]=\mathrm{Predadv}[A,G]\). So if \(G\) is secure, it is unpredictable.

Given a predictor \(A\) that chooses index \(i\), define \(B(r)\): give \(r[0..i-1]\) to \(A\), and output 1 iff \(A\)'s guess equals \(r[i]\). In Experiment 0, \(\Pr[W_0]=1/2+\varepsilon\). In Experiment 1, \(r[i]\) is a fresh uniform bit independent of \(A\)'s view, so \(\Pr[W_1]=1/2\) BS p.65.

Advantage: \(\mathrm{PRGadv}[B,G]=|(1/2+\varepsilon)-1/2|=|\varepsilon|=\mathrm{Predadv}[A,G]\).

Conclusion: if \(G\) is secure, the left side is negligible, so \(\mathrm{Predadv}[A,G]\) is negligible for every efficient \(A\): \(G\) is unpredictable. ∎

Proof of (b).

Approach. Contrapositive via a hybrid argument, then the distinguisher/predictor lemma.

Assume. \(A\) is an efficient distinguisher with \(\mathrm{PRGadv}[A,G]=\varepsilon\) (absolute value dropped, Section 3.1).

Recall. The hybrid lemma. BS Lemma 3.5 (distinguisher ⇒ predictor). The closure facts.

WTS: an efficient predictor \(B\) with \(\mathrm{Predadv}[B,G]=\varepsilon/L\). So if \(G\) is unpredictable, then \(\varepsilon=L\cdot\mathrm{negl}\) is negligible, i.e. \(G\) is secure.

This direction is the interesting one: any statistical test that works can be turned into a next-bit predictor.
  1. Hybrids. Let \(H_j\) = the first \(L-j\) bits of \(G(s)\) followed by \(j\) uniform bits. Then \(H_0\) is pseudorandom and \(H_L\) is uniform. If \(A\) distinguishes with advantage \(\varepsilon\), a random adjacent pair is distinguished with advantage \(\varepsilon/L\) on average BS p.67 V p.150.
  2. Distinguisher/predictor lemma. Let \(X\) be side information, \(B\) a bit correlated with \(X\), and \(R\) a uniform bit independent of both. Suppose \(d\) satisfies \(\Pr[d(X,B)=1]-\Pr[d(X,R)=1]=\varepsilon\). Then the guess “\(R\) if \(d(X,R)=1\), else \(\bar R\)” equals \(B\) with probability exactly \(1/2+\varepsilon\) BS Lemma 3.5, p.66 (full proof there; it is a conditioning calculation on \(B=R\) vs. \(B\ne R\)).
  3. The predictor. Pick \(\omega\in\{1..L\}\) at random. Ask for the first \(L-\omega\) bits \(x\). Append \(\omega\) random bits \(r_1\cdots r_\omega\) and run \(A\) on \(x\,\|\,r_1\cdots r_\omega\). If \(A\) outputs 1, guess \(r_1\); otherwise guess \(\bar r_1\). By steps 1–2, the success probability is \(1/2+\varepsilon/L\) BS p.67–68. Vadhan gives the same computation in one display V p.151.

    Advantage: \(\mathrm{Predadv}[B,G]=\varepsilon/L=\mathrm{PRGadv}[A,G]/L\), i.e. \(\mathrm{PRGadv}[A,G]=L\cdot\mathrm{Predadv}[B,G]\).

    Why this is negligible: if \(G\) is unpredictable, \(\mathrm{Predadv}[B,G]\) is negligible. The output length \(L\) is polynomial, so \(L\cdot\mathrm{Predadv}[B,G]\) is negligible by the closure fact. So \(\mathrm{PRGadv}[A,G]\) is negligible for every efficient \(A\): \(G\) is secure. ∎

Why we need this. In Section 2 of the site, we'll build a PRG by showing that its last output bit is unpredictable from the earlier ones (the Goldreich–Levin “hardcore bit”). Theorem 7.1(b) turns that into full pseudorandomness. HILL's “hidden bit” is this same idea HILL §3.5, Def. 3.10, p.1374 HILL §1.1, p.1366.

8. From PRGs to derandomization: the lecture's “Hardness ⟹ Derandomization”, made rigorous

Change of setting. Sections 2–7 were about cryptographic PRGs: they fool every efficient adversary, with negligible advantage. In most of this section, adversaries are circuits of one fixed size \(m\), and the advantage only has to be at most \(1/8\). No negligible functions appear until Section 8.6, where we come back to cryptographic PRGs. Definitions and theorems in this restricted setting are drawn in green boxes like this one.

8.1 The goal

Recall the lecture's plan from Section 1 455-PTC2 p.2–3. To show \(\BPP=\Pclass\), take a \(\BPP\) machine \(M\) (poly-time, error \(\le 1/3\)) and a generator \(G\) that stretches an \(O(\log n)\)-bit seed into the random bits \(M\) needs. Run \(M(x,G(s))\) for every seed \(s\) and take the majority. Two things have to hold:

  1. \(G\) has to be computable in polynomial time, and its seed has to be \(O(\log n)\) bits, so there are only polynomially many seeds.
  2. \(G\)'s output has to be “random enough” that the majority answer is still correct.

The natural first idea is to use the PRGs we defined in Section 4.

8.2 First attempt: cryptographic PRGs. This fails.

Fact 8.1: a cryptographic PRG cannot have an \(O(\log m)\)-bit seed
V Problem 7.3(1), p.178 (stated as an exercise) BS p.48, Exercise 3.5 (the seed space must be super-poly). Proof: Claude
Proof (an adversary in the game of Figure 2).

Approach. Direct attack: exhibit one efficient adversary (seed enumeration) that wins.

Assume. \(G:\bits^d\to\bits^m\) is computable in polynomial time, with \(d\le c\log m\) for a constant \(c\).

Recall. Cryptographic security requires negligible advantage against every efficient adversary. \(G\) has at most \(2^d\) outputs.

WTS: an efficient adversary whose advantage is not negligible, so \(G\) is not a secure cryptographic PRG.

Suppose \(G:\bits^d\to\bits^m\) with \(d \le c\log m\). Adversary \(A(r)\): try every seed \(s\in\bits^d\), and output 1 if some \(G(s)=r\). This is the image test from Section 3.2.
  • \(\Pr[W_0]=1\).
  • \(\Pr[W_1]\le 2^{d-m}\le 1/2\).
  • \(A\) runs in time \(2^d\cdot\mathrm{time}(G)\le m^c\cdot\poly(m)\), which is polynomial.

Advantage: \(\mathrm{PRGadv}[A,G]=1-\frac{|\mathrm{Im}(G)|}{2^m}\ge 1-2^{d-m}\ge\frac12\).

Why this is not negligible: with \(c=1\), a negligible function would be \(\lt 1/m\) for all large \(m\), but this one is \(\ge 1/2\) for every \(m\). Since \(A\) is efficient, \(G\) is not a secure (cryptographic) PRG. ∎

What this says about the lecture. The lecture's PRG takes \(O(\log n)\) seed bits, runs in polynomial time, and “fools poly-time TMs” 455-PTC2 p.2. Read literally, that's a cryptographic PRG with a logarithmic seed, which Fact 8.1 rules out. The seed-enumeration adversary is itself a poly-time TM; its polynomial is just bigger than \(G\)'s Claude: this observation. So cryptographic PRGs ask for too much: their seed space must be superpolynomial, and our plan needs it to be polynomial.

8.3 The fix: ask only for what the simulation needs

Look at what the simulation actually requires. For one \(\BPP\) machine \(M\) and one input \(x\), the pseudorandom bits only have to fool one test, “run \(M(x;\cdot)\)”. With \(x\) hard-coded, that test is a circuit of some fixed polynomial size \(m=n^c\) 455-BC1. And they only have to keep \(M\)'s error below \(1/2\), so a constant advantage bound like \(1/8\) is enough. That gives the same PRG game (Figure 2) with a restricted set of players:

Figure 5. The restricted PRG game used for derandomization. Claude: figure, following V Def. 7.3, p.142.

Definition 8.2 (\((t,\varepsilon)\) PRG; derandomization PRG)
\(G:\bits^d\to\bits^m\) (with \(d\lt m\)) is a \((t,\varepsilon)\) PRG if every circuit of size at most \(t\) has \(\mathrm{PRGadv}\le\varepsilon\) against \(G\) V Def. 7.1 & 7.3, p.141–142.
A derandomization PRG is a family of \((m,1/8)\) PRGs \(G_m:\bits^{d(m)}\to\bits^m\), one for each output length \(m\).

Comparing with Section 4: this is a special case of the cryptographic requirement, not a rival to it. It asks to fool only some of the adversaries (size \(\le m\)), and only up to a constant. Section 8.6 makes this precise: every cryptographic PRG secure against circuits yields one. And it escapes Fact 8.1. The seed-enumeration adversary has size about \(2^d\cdot\mathrm{time}(G)\), which is bigger than \(m\), so it isn't allowed in the restricted game V p.143, p.146. By the same token, \(G_m\) may itself take longer than \(m\) to compute. It only has to beat circuits of size \(m\), not circuits as big as itself V Def. 7.7, p.143.

8.4 Main theorem: log-seed derandomization PRGs give \(\BPP=\Pclass\)

Theorem 8.3
Suppose there is a derandomization PRG \(G_m:\bits^{d(m)}\to\bits^m\) with seed length \(d(m)=O(\log m)\) that is computable in time \(\poly(m)\). Then \(\BPP=\Pclass\).
V Thm. 7.5, p.143 (general seed length) and item (3) on V p.144 (this special case).
Proof.

Approach. Direct: simulate the BPP machine on every seed and take the majority. Correctness uses the fact that the machine with \(x\) hard-coded is a legal adversary in Figure 5's restricted game.

Assume. \(G_m\) is an \((m,1/8)\) PRG with seed length \(O(\log m)\), computable in \(\poly(m)\) time. \(L\in\BPP\) is decided by a poly-time \(A(x;r)\) with error \(\le1/3\).

Recall. TM-to-circuit conversion 455-BC1. Definition 8.2. \(\Pclass\subseteq\BPP\) holds trivially.

WTS: a deterministic polynomial-time algorithm deciding \(L\), i.e. \(L\in\Pclass\). Since \(L\in\BPP\) was arbitrary, \(\BPP=\Pclass\).

V p.143, specialized to \(d=O(\log m)\).

Setup. Let \(L\in\BPP\) be decided by a poly-time machine \(A(x;r)\) with error at most \(1/3\). By TM-to-circuit conversion 455-BC1, choose a constant \(c\) such that, on inputs of length \(n\), \(A\) uses at most \(n^c\) random bits and the test circuit \(T\) below has size at most \(n^c\). Pad \(A\)'s random string to exactly \(n^c\) bits, and set \(m=n^c\) and \(G=G_m\).

Claim. For every \(x\) of length \(n\), \(A(x;G(s))\) is correct for more than half of the seeds \(s\).

Proof of claim. Fix \(x\) and let \(T(r)=1\) iff \(A(x;r)\) gives the correct answer for \(x\). With \(x\) and the correct answer hard-coded, \(T\) is a circuit of size about \(m\). So \(T\) is allowed to play the game of Figure 5.

  • \(\Pr[W_1]=\Pr_{r\text{ uniform}}[A(x;r)\text{ correct}]\ge 2/3\), since \(A\) is a \(\BPP\) machine.
  • \(\Pr[W_0]=\Pr_{s}[A(x;G(s))\text{ correct}]\), the fraction of good seeds.

\(G\) is an \((m,1/8)\) PRG, so \(|\Pr[W_0]-\Pr[W_1]|\le 1/8\). Hence the fraction of good seeds is \(\Pr[W_0]\ge 2/3-1/8=13/24\gt 1/2\). Note: \(x\) is used as nonuniform advice inside \(T\). This is exactly why Definition 8.2 talks about circuits V p.143.

Deterministic algorithm. On input \(x\), for every seed \(s\in\bits^{d(m)}\), compute \(G(s)\) and run \(A(x;G(s))\). Output the majority answer. By the claim, the majority is always correct.

Running time.

  • There are \(2^{d(m)}=2^{O(\log m)}=m^{O(1)}=n^{O(c)}\) seeds, which is polynomial.
  • Each seed costs \(\poly(m)=\poly(n)\) to compute \(G(s)\), plus \(\poly(n)\) to run \(A\).
  • Total: polynomial in \(n\). So \(L\in\Pclass\). ∎

This is the lecture's sketch, made precise 455-PTC2 p.2–3. The only change is the kind of PRG: the restricted one of Definition 8.2, not a cryptographic one.

8.5 Where would log-seed derandomization PRGs come from?

Not from cryptography (Fact 8.1). They come from circuit lower bounds, which is exactly the course's “Hardness ⟹ Derandomization” and the remark in Boolean Circuits 1 that “circuit complexity lower bounds imply derandomization” 455-BC1. We state this result without proof:

Theorem 8.4 (Nisan–Wigderson ’94; Impagliazzo–Wigderson ’97); stated, not proved
Suppose there is a function \(f\in\mathsf{E}=\DTIME(2^{O(\ell)})\) and a constant \(\alpha\gt 0\) such that, for all large \(\ell\), no circuit of size \(2^{\alpha\ell}\) computes \(f\) correctly on every input of length \(\ell\). Then for every \(m\) there is a generator \(G_m:\bits^{O(\log m)}\to\bits^m\), computable in \(\poly(m)\) time, such that no circuit of size \(m\) has advantage more than \(1/m\). In particular (for \(m\ge 8\)) it is a derandomization PRG, so by Theorem 8.3, \(\BPP=\Pclass\).
V Thm. 7.63 & Cor. 7.64(1), p.171 (worst-case hardness) V Thm. 7.19 & Cor. 7.20, p.153–154 (average-case hardness)

The idea, for context only V Def. 7.21, Thm. 7.24, p.154:

  • Choose sets \(S_1,\dots,S_m\) of seed positions, each of size \(\ell=O(\log m)\), any two overlapping in at most \(\log m\) positions.
  • Output \(f(\text{seed bits in }S_1),\dots,f(\text{seed bits in }S_m)\). Computing this takes \(m\cdot 2^{O(\ell)}=\poly(m)\) time, more than the size-\(m\) circuits it fools, which Definition 8.2 allows.
  • The proof uses Yao's next-bit theorem (Section 7), so a distinguisher yields a predictor for some output bit. Because the overlaps are small, the other output bits can be hard-coded as tiny lookup tables, and the predictor turns into a small circuit that computes \(f\) on random inputs noticeably better than a coin flip.
  • Going from “hard in the worst case” to “hard on random inputs” requires another, longer argument (hardness amplification, V §7.5–7.6). We don't cover it.

Two more facts:

  • Such PRGs exist non-constructively. A random function \(G:\bits^{O(\log m)}\to\bits^m\) is an \((m,1/8)\) PRG with high probability (Chernoff + union bound over the \(2^{\poly(m)}\) circuits of size \(m\)) V Prop. 7.8, p.144. Hard-coding its truth table as advice and running the proof of Theorem 8.3 re-proves \(\BPP\subseteq\Ppoly\) V p.144, which we saw in class by a different route 455-BC2. So the whole difficulty is explicitness: computing \(G\) efficiently.
  • The converse direction (derandomizing PIT ⇒ circuit lower bounds) appears in the lecture only as a statement 455-PTC2 p.7. We leave it as a statement too.

8.6 What cryptographic PRGs do give: \(\BPP\subseteq\SUBEXP\)

Cryptographic PRGs can't reach Theorem 8.3's hypothesis, but they reach a weaker one. First note what the proof of Theorem 8.3 used the seed length for: only to count the seeds.

Remark 8.5 (other seed lengths)
Running the proof of Theorem 8.3 with a derandomization PRG of seed length \(d(m)\), computable in time \(t(m)\), gives a deterministic algorithm running in time about \(2^{d(n^c)}\cdot\big(t(n^c)+\poly(n)\big)\) V Thm. 7.5, p.143. For example, \(d(m)=m^{\varepsilon}\) for every \(\varepsilon\gt0\) gives \(\BPP\subseteq\bigcap_{\varepsilon}\DTIME(2^{n^\varepsilon})=\SUBEXP\) V p.144.
Theorem 8.6 (cryptographic PRGs ⇒ \(\BPP\subseteq\SUBEXP\))
If there is a cryptographic PRG secure against polynomial-size circuits, then \(\BPP\subseteq\SUBEXP\). V Thm. 7.11 & Cor. 7.12, p.146 (stated; proof not given there). Written-out proof: Claude
Proof.

Approach. Direct construction in three steps: stretch the cryptographic PRG, check that it is a derandomization PRG, then apply Remark 8.5.

Assume. \(G:\bits^n\to\bits^{n+1}\) is a cryptographic PRG secure against polynomial-size circuits. Fix any constant \(\varepsilon\gt0\).

Recall. Theorem 6.2 (stretching, with advantage loss \(\times\) the number of iterations). The closure facts and the definition of negligible (with \(c=1\)). Remark 8.5.

WTS: for every \(\varepsilon\), an \((m,1/8)\) PRG with seed length \(\lceil m^\varepsilon\rceil\) computable in \(\poly(m)\) time. Hence every \(L\in\BPP\) is in \(\DTIME(2^{n^\delta})\) for every \(\delta\gt0\).

Let \(G:\bits^n\to\bits^{n+1}\) be a cryptographic PRG secure against polynomial-size circuits. Fix \(\varepsilon\gt 0\).

  1. Stretch. For each \(m\), let \(n=\lceil m^\varepsilon\rceil\). Apply Theorem 6.2 with \(m-n\) iterations to get \(G_m:\bits^{n}\to\bits^m\), computable in \(\poly(m)\) time. (We use the nonuniform version of Theorem 6.2: the same proof, with \(B\) hard-coding rather than sampling.)
    Advantage: for every efficient \(A\), \(\mathrm{PRGadv}[A,G_m]=(m-n)\cdot\mathrm{PRGadv}[B,G]\le n^{1/\varepsilon}\cdot\mathrm{PRGadv}[B,G]\).
    Why this is negligible: \(\mathrm{PRGadv}[B,G]\) is negligible in \(n\) because \(G\) is secure, and \(n^{1/\varepsilon}\) is a polynomial in \(n\) (\(\varepsilon\) is a fixed constant). So the product is negligible by the closure fact of Section 2.1. Hence \(G_m\) is a secure cryptographic PRG with security parameter \(n\).
  2. Size-\(m\) circuits are among the adversaries already covered. A circuit \(T\) of size \(m\le n^{1/\varepsilon}\) has size polynomial in \(n\), so by step 1, \(\mathrm{PRGadv}[T,G_m]\) is negligible in \(n\).
    From negligible to \(1/8\): apply the definition of negligible with \(c=1\). For all large \(n\), \(\mathrm{PRGadv}[T,G_m]\lt 1/n\le 1/8\). (Strictly, the cryptographic definition talks about one circuit family. Taking, for each \(m\), the best size-\(m\) circuit gives a single polynomial-size family, so the bound holds for all size-\(m\) circuits at once.)
    So for all large \(m\), \(G_m\) is an \((m,1/8)\) PRG with seed length \(\lceil m^\varepsilon\rceil\), computable in \(\poly(m)\) time: a derandomization PRG. (Finitely many small input lengths can be handled by a lookup table.)
  3. Apply Remark 8.5. For \(L\in\BPP\) with circuit-size exponent \(c\), we get \(L\in\DTIME(2^{O(n^{c\varepsilon})}\poly(n))\). Since \(\varepsilon\) was arbitrary, choose \(\varepsilon=\delta/c\) to get \(L\in\DTIME(2^{n^{\delta}})\) for every \(\delta\gt 0\), i.e. \(L\in\SUBEXP\). ∎

Step 2 is where the two settings meet. “Every polynomial-size adversary has negligible advantage” contains “size-\(m\) adversaries have advantage \(\le 1/8\)” as a special case.
