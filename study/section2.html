What this page proves

Section 1 showed that a cryptographic PRG secure against circuits gives \(\BPP\subseteq\SUBEXP\) (S1 Theorem 8.6). It left open where cryptographic PRGs come from. This page introduces one-way functions, the precise version of the lecture's “hard functions”, and proves that they give PRGs. This is the HILL theorem:

Theorem (HILL)
One-way functions exist if and only if pseudorandom generators exist. HILL Thm. 6.3, p.1385 V Thm. 7.11, p.146

We prove (⇐) in full (§2). We prove (⇒) in full for one-to-one one-way functions (§3–§7), and outline the general case (§9). Everything on this page is about cryptographic PRGs: every efficient adversary, negligible advantage.

Conventions (from S1 §2.4):

  • Distinguishing games use \(\Pr[W_0]-\Pr[W_1]\).
  • Prediction games have success probability \(\frac12+\varepsilon\), and \(\varepsilon\) is the prediction advantage.
  • Every proof computes the advantage explicitly and then argues why it is or isn't negligible.

Which adversaries? Every reduction on this page works for both uniform PPT adversaries and circuit adversaries. If the adversary we start from is a circuit, the adversary we build is a circuit too. So “secure against circuits” in gives “secure against circuits” out, which is what S1 Theorem 8.6 needs Claude.

1. One-way functions

Definition 1.1 (one-way function, OWF)
\(f:\bits^*\to\bits^*\) is one-way if
  1. \(f\) is computable in polynomial time, and
  2. for every efficient \(A\), \(\displaystyle\Pr_{x\leftarrow\bits^n}\big[f(A(f(x)))=f(x)\big]\) is negligible in \(n\).
MIT p.16-4 HILL Def. 3.2, p.1372 V Def. 7.10, p.145 (Vadhan's version is against nonuniform \(A\))
  • “Find some preimage,” not “find \(x\)”. \(A\) succeeds if it outputs any \(x'\) with \(f(x')=f(x)\). If success meant recovering \(x\) itself, a constant function \(f(x)=1\) would count as “one-way”: you can never tell which \(x\) was used, even though inverting it is trivial MIT p.16-4.
  • Average case, not worst case. \(f\) must be hard to invert on a random input. NP-hardness is a worst-case notion (“some instance is hard”), which is useless for cryptography, where we need almost every key to be secure. This is why we assume OWFs instead of just \(\Pclass\ne\NP\) MIT §4, p.16-3–16-4 V p.145.
  • The limits on how hard \(f\) can be. Inverting can't be easier than evaluating \(f\), and brute force over all \(2^n\) inputs always works. So the possible security levels lie between those two extremes HILL p.1372.
  • Candidates, in one sentence. Multiplying two random \(n/2\)-bit numbers is believed one-way, because inverting it is factoring V p.145. The RSA function \(x\mapsto x^e \bmod N\) is the familiar related example BS §10.3.
  • Special cases used on this page.
    • One-way permutation: \(f\) is a bijection on \(\bits^n\).
    • One-to-one OWF: \(f\) is injective but may be length-increasing.
    • Regular OWF: every image has the same number of preimages.
    HILL Def. 2.11–2.12, p.1370 V p.147

2. The easy direction: PRG ⇒ one-way function

A short reduction in the style of S1 §5: from an adversary against one primitive, build an adversary against another.

Theorem 2.1 (PRG ⇒ OWF)
If \(G:\bits^n\to\bits^{\ell(n)}\) is a secure PRG with \(\ell(n)\ge 2n\), then \(G\) is a one-way function. (Any PRG can first be stretched to \(\ell\ge 2n\) using S1 Theorem 6.2.)
Idea: MIT p.16-4 (one-sentence argument). HILL credit this direction to Levin '87 HILL Thm. 6.3, p.1385. Written-out proof: Claude
Proof.

Approach. Contrapositive, via a security reduction that turns an inverter into a distinguisher.

Assume. (Contrapositive) \(G\) is not one-way: some efficient \(A\) inverts it with non-negligible probability \(p(n)\). Also \(\ell(n)\ge 2n\).

Recall. The PRG game and definition (S1 §4.1). \(G\) has at most \(2^n\) outputs. “Not negligible” means: for some \(c\), at least \(1/n^c\) for infinitely many \(n\).

WTS: an efficient \(B\) with non-negligible \(\mathrm{PRGadv}[B,G]\), i.e. \(G\) is not a secure PRG.

Contrapositive. Suppose an efficient \(A\) inverts \(G\) with non-negligible probability \(p(n)=\Pr_{s}[G(A(G(s)))=G(s)]\). Define the distinguisher \(B(y)\): compute \(s'=A(y)\), and output 1 iff \(G(s')=y\). \(B\) is efficient because \(A\) and \(G\) are.
  • Experiment 0 (\(y=G(s)\)): \(B\) outputs 1 exactly when \(A\) inverts successfully, so \(\Pr[W_0]=p(n)\).
  • Experiment 1 (\(y\) uniform in \(\bits^{\ell}\)): \(B\) can output 1 only if \(y\in\mathrm{Im}(G)\), and \(|\mathrm{Im}(G)|\le 2^n\). So \(\Pr[W_1]\le 2^{n-\ell}\le 2^{-n}\).

Advantage: \(\mathrm{PRGadv}[B,G]=\Pr[W_0]-\Pr[W_1]\ge p(n)-2^{-n}\).

Why this is not negligible: \(p\) is not negligible, so there is a constant \(c\) with \(p(n)\ge 1/n^c\) for infinitely many \(n\). For all large \(n\), \(2^{-n}\le \frac{1}{2n^c}\). So for infinitely many \(n\), \(\mathrm{PRGadv}[B,G]\ge \frac1{n^c}-\frac1{2n^c}=\frac{1}{2n^c}\ge\frac{1}{n^{c+1}}\) (for \(n\ge 2\)). A negligible function would have to be \(\lt 1/n^{c+1}\) for all large \(n\), so \(\mathrm{PRGadv}[B,G]\) is not negligible and \(G\) is not secure. ∎


Why \(\ell\ge 2n\)? With only \(\ell = n+1\), the bound on \(\Pr[W_1]\) is \(1/2\), and \(p(n)-1/2\) could be negative. Stretching first avoids this.

3. Hardcore bits

The problem. A one-way function only promises that \(x\) is hard to recover as a whole. Individual bits of \(x\) can leak completely. Example Claude: if \(f'\) is one-way, so is \(f(x_1,x_2)=(x_1,f'(x_2))\), where \(x_1,x_2\) are the two halves of \(x\). Yet \(f(x)\) reveals the whole first half of \(x\). To build a PRG we need at least one bit about \(x\) that is provably unpredictable from \(f(x)\).

Definition 3.1 (hardcore bit), a prediction game
A poly-time computable \(b:\bits^n\to\bits\) is a hardcore bit for \(f\) if for every efficient predictor \(P\), $$\Pr_{x\leftarrow\bits^n}\big[P(f(x))=b(x)\big]\le \tfrac12+\varepsilon(n)\quad\text{with }\varepsilon\text{ negligible.}$$ \(\varepsilon\) is \(P\)'s prediction advantage. Pandey p.6-1 HILL Def. 3.10 (“hidden bit”), p.1374

As with next-bit unpredictability (S1 §7), this prediction game is equivalent to a two-experiment game, with exactly the same advantage:

Lemma 3.2 (predicting ⇔ distinguishing)
Let \(X\) be uniform on \(\bits^n\), and let \(\beta\) be a uniform bit independent of \(X\). Compare $$\text{Experiment 0: }(f(X),\,b(X))\qquad\text{vs.}\qquad\text{Experiment 1: }(f(X),\,\beta).$$
  • (a) From a predictor with prediction advantage \(\varepsilon\), we get a distinguisher with \(\Pr[W_0]-\Pr[W_1]=\varepsilon\).
  • (b) From a distinguisher with \(\Pr[W_0]-\Pr[W_1]=\varepsilon\), we get a predictor with prediction advantage \(\varepsilon\).
So \(b\) is hardcore for \(f\) iff the two experiments are computationally indistinguishable. BS Lemma 3.5, p.66 (part b) BS Thm. 3.4, p.64 (same argument as part a) HILL Prop. 4.3, p.1376
Proof.

Approach. Two direct security reductions, one for each direction.

Assume. (a) A predictor \(P\) with success probability \(\frac12+\varepsilon\). (b) A distinguisher \(D\) with \(\Pr[W_0]-\Pr[W_1]=\varepsilon\).

Recall. \(\beta\) is independent of \(f(X)\). The distinguisher/predictor lemma BS Lemma 3.5.

WTS: (a) a distinguisher with advantage exactly \(\varepsilon\); (b) a predictor with success probability exactly \(\frac12+\varepsilon\).

(a) Given predictor \(P\), let \(D(y,c)=1\) iff \(P(y)=c\).

  • Experiment 0: \(\Pr[W_0]=\Pr[P(f(X))=b(X)]=\frac12+\varepsilon\).
  • Experiment 1: \(\beta\) is independent of \(P\)'s input, so \(\Pr[W_1]=\Pr[P(f(X))=\beta]=\frac12\).

Advantage: \(\Pr[W_0]-\Pr[W_1]=\varepsilon\).

(b) Given distinguisher \(D\), let \(P(y)\): pick a random bit \(c\); if \(D(y,c)=1\) output \(c\), otherwise output \(1-c\). This is the distinguisher/predictor lemma BS Lemma 3.5, p.66, used in the proof of S1 Theorem 7.1(b), with side information \(f(X)\), hidden bit \(b(X)\), and random bit \(c\). It gives success probability exactly \(\frac12+\varepsilon\) (full calculation in BS). ∎

4. The Goldreich–Levin theorem

For a general one-way function, we don't know of a hardcore bit for \(f\) itself. Goldreich and Levin found one for a slightly modified function, which adds a public random string \(r\). The bit is the inner product mod 2, the parity of a random subset of \(x\)'s bits:

$$\langle x,r\rangle = x_1r_1\oplus x_2r_2\oplus\cdots\oplus x_nr_n .$$

(This is the same inner-product function \(\mathrm{IP}\) that appears in the course's circuit lower bounds 455-BC3.)

Theorem 4.1 (Goldreich–Levin)
Let \(f\) be any one-way function. For \(x,r\in\bits^n\), \(\langle x,r\rangle\) is a hardcore bit for \(f'(x,r)=(f(x),r)\). That is, for every efficient \(P\), $$\Pr_{x,r}\big[P(f(x),r)=\langle x,r\rangle\big]\le\tfrac12+\mathrm{negl}(n).$$ Two-experiment form (by Lemma 3.2): \((f(X),R,\langle X,R\rangle)\) and \((f(X),R,\beta)\) are computationally indistinguishable. HILL Props. 4.1–4.3, p.1376 (stated, credited to [GL89], not proved there) Pandey §2.4 Trevisan Thm. 1–2 Barak Thm. 3

Note that \(r\) is a public input: it's part of \(f'\)'s output. The security parameter is \(n=|x|\) (S1 §2.2). Two facts about \(\langle\cdot,\cdot\rangle\) drive the whole proof:

  • Linearity: \(\langle x,r\oplus r'\rangle=\langle x,r\rangle\oplus\langle x,r'\rangle\).
  • Reading off a bit: \(\langle x,e_i\rangle=x_i\), where \(e_i\) is the \(i\)-th unit vector.

4.1 Proof overview

Approach. Contrapositive, via a security reduction: from a good predictor for \(\langle x,r\rangle\) we build an inverter for \(f\), in four steps (Claims 4.2–4.4).

Assume. (Contrapositive) Some efficient \(P\) has \(\Pr_{x,r}[P(f(x),r)=\langle x,r\rangle]=\frac12+\varepsilon(n)\), with \(\varepsilon\) not negligible: \(\varepsilon(n)\ge1/n^c\) for some constant \(c\) and infinitely many \(n\).

Recall. The definition of a one-way function (§1). Linearity of \(\langle\cdot,\cdot\rangle\). Pairwise independence and Chebyshev (from the course). What “not negligible” means.

WTS: an efficient inverter \(I\) with \(\Pr_x[f(I(f(x)))=f(x)]\) not negligible. This contradicts \(f\) being one-way.

Contrapositive. Suppose an efficient \(P\) has $$\Pr_{x,r}[P(f(x),r)=\langle x,r\rangle]=\tfrac12+\varepsilon(n)$$ with \(\varepsilon\) not negligible. So there is a constant \(c\) with \(\varepsilon(n)\ge 1/n^c\) for infinitely many \(n\). We build an efficient inverter \(I\) for \(f\) that succeeds with non-negligible probability. \(I\) hard-codes \(c\) and uses \(\varepsilon:=1/n^c\) as its estimate. The analysis below is for the infinitely many \(n\) where \(P\)'s advantage really is at least \(1/n^c\).

The proof goes in four steps, getting harder as \(P\) gets weaker: good \(x\)'s, then a perfect predictor, then a \(\frac34\)-good predictor, then the real case Pandey §2.4 and the previous lecture's warm-ups it refers to.

4.2 Step 1: many \(x\)'s are good

For each \(x\), let \(s_x=\Pr_r[P(f(x),r)=\langle x,r\rangle]\), \(P\)'s success rate on that particular \(x\). Call \(x\) good if \(s_x\ge\frac12+\frac\varepsilon2\).

Claim 4.2
\(\Pr_x[x\text{ good}]\ge\varepsilon/2\). Pandey eq. (3), p.6-4
Proof.

Approach. Direct averaging argument.

Assume. \(P\)'s overall success is \(\frac12+\varepsilon\), and each \(s_x\le1\).

Recall. Overall success is the average of the per-\(x\) success rates: \(\mathbb{E}_x[s_x]=\frac12+\varepsilon\).

WTS: \(q=\Pr_x[x\text{ good}]\ge\varepsilon/2\).

Let \(q=\Pr_x[x\text{ good}]\). A good \(x\) has \(s_x\le 1\). A bad \(x\) has \(s_x\lt\frac12+\frac\varepsilon2\). So \(\frac12+\varepsilon=\mathbb{E}_x[s_x]\le q\cdot1+(1-q)(\frac12+\frac\varepsilon2)\le q+\frac12+\frac\varepsilon2\). Hence \(q\ge\varepsilon/2\). ∎

From now on, fix a good \(x\) and write \(y=f(x)\). The inverter is given \(y\) and doesn't know \(x\); the analysis is what knows \(x\).

4.3 Step 2 (warm-up): a perfect predictor

If \(s_x=1\), then \(P(y,e_i)=\langle x,e_i\rangle=x_i\), and \(n\) queries recover \(x\). This fails as soon as \(P\) is imperfect. \(e_i\) is one fixed point, and \(P\) might be wrong on every unit vector while still being right on most \(r\). The fix is to only ever query \(P\) at uniformly random-looking points, where its success rate \(s_x\) applies Claude: framing.

4.4 Step 3 (warm-up): a predictor with \(s_x\ge\frac34+\frac\varepsilon2\)

Pick a uniform \(r\) and compute \(P(y,r)\oplus P(y,r\oplus e_i)\). If both answers are correct, this equals \(\langle x,r\rangle\oplus\langle x,r\oplus e_i\rangle=x_i\) by linearity. Both \(r\) and \(r\oplus e_i\) are uniform, so each answer is wrong with probability at most \(\frac14-\frac\varepsilon2\). By a union bound, both are right with probability at least \(1-2(\frac14-\frac\varepsilon2)=\frac12+\varepsilon\). Repeating with independent \(r\)'s and taking a majority vote recovers \(x_i\) with high probability (Hoeffding, as in the course's error reduction 455-PTC2 p.4–5) Pandey p.6-1 (referring to the warm-up from the previous lecture).

Why this breaks at \(\frac12+\varepsilon\): each query is then wrong with probability nearly \(\frac12\). The union bound over two queries only says both are right with probability \(\ge\varepsilon\), which is useless for a majority vote. The fix: guess the value \(\langle x,r\rangle\) instead of asking \(P\), so only one query can be wrong.

4.5 Step 4: the real case, \(s_x\ge\frac12+\frac\varepsilon2\)

Guessing \(\langle x,r\rangle\) for many independent \(r\)'s would succeed with exponentially small probability. The trick: guess only a few values and generate many more by linearity. The generated points are only pairwise independent, but Chebyshev only needs pairwise independence Pandey §2.3–2.4. Trevisan credits this version of the proof to Rackoff Trevisan, p.1.

Inverter \(I(y)\)
Parameters: \(t=\lceil\log_2(2n/\varepsilon^2+1)\rceil\), and \(m=2^t-1\ge 2n/\varepsilon^2\).
  1. Pick \(s_1,\dots,s_t\in\bits^n\) uniformly and independently. For each nonempty \(T\subseteq\{1..t\}\), let \(r_T=\bigoplus_{j\in T}s_j\). These are \(m\) strings.
  2. For each guess \((b_1,\dots,b_t)\in\bits^t\), meant to be \(\langle x,s_1\rangle,\dots,\langle x,s_t\rangle\):
    • for each nonempty \(T\), set \(b_T=\bigoplus_{j\in T}b_j\), meant to be \(\langle x,r_T\rangle\);
    • for each \(i=1..n\), set \(z_i=\mathrm{majority}_T\big(b_T\oplus P(y,\,r_T\oplus e_i)\big)\);
    • if \(f(z)=y\), output \(z=z_1\cdots z_n\) and stop.
  3. If no guess worked, output anything.
Pandey §2.4, p.6-4 (same algorithm, with \(m=2n/\varepsilon^2\)) Trevisan Lemma 3
Claim 4.3 (pairwise independence)
Each \(r_T\) is uniform on \(\bits^n\), and for \(T\ne T'\), \(r_T\) and \(r_{T'}\) are independent. The same holds for the shifted points \(r_T\oplus e_i\). Pandey §2.3, p.6-3 Barak
Proof.

Approach. Direct: condition on all but one of the seeds.

Assume. \(s_1,\dots,s_t\) are independent and uniform, and \(T\ne T'\) are nonempty subsets.

Recall. The definition of pairwise independence. XOR-ing an independent uniform string onto any string gives a uniform string.

WTS: each \(r_T\) is uniform, and \(r_T,r_{T'}\) are independent for \(T\ne T'\); the same holds after XOR-ing with \(e_i\).

Claude Since \(T\ne T'\), some \(j\) is in exactly one of them; say \(j\in T'\setminus T\) (the other case is symmetric). Condition on every \(s_{j'}\) with \(j'\ne j\). Then \(r_T\) is fixed, while \(r_{T'}=s_j\oplus(\text{fixed})\) is uniform. So given any value of \(r_T\), \(r_{T'}\) is uniform: they are independent, and \(r_{T'}\) is uniform. Uniformity of each single \(r_T\) is the same argument with any \(j\in T\). XOR-ing every point with the fixed string \(e_i\) preserves all of this. ∎
Claim 4.4
Fix a good \(x\) and consider the iteration with the correct guess \(b_j=\langle x,s_j\rangle\) for all \(j\). With probability at least \(\frac12\) over the choice of \(s_1,\dots,s_t\), that iteration produces \(z=x\). Pandey eq. (4), p.6-5
Proof.

Approach. Direct: view the votes as pairwise-independent indicator variables, then use Chebyshev and a union bound.

Assume. \(x\) is good (\(s_x\ge\frac12+\frac\varepsilon2\)), the guess is correct (\(b_j=\langle x,s_j\rangle\)), and \(m\ge 2n/\varepsilon^2\).

Recall. Linearity of \(\langle\cdot,\cdot\rangle\) and \(\langle x,e_i\rangle=x_i\). Claim 4.3. Chebyshev's inequality, and the fact that variances of pairwise-independent variables add (each indicator has variance \(\le\frac14\)).

WTS: \(\Pr[z\ne x]\le\frac12\) over the choice of \(s_1,\dots,s_t\).

With the correct guess, linearity gives \(b_T=\langle x,r_T\rangle\) for every \(T\). Also \(\langle x,r_T\oplus e_i\rangle=\langle x,r_T\rangle\oplus x_i\). So the vote \(b_T\oplus P(y,r_T\oplus e_i)\) equals \(x_i\) exactly when \(P\) answers correctly on the point \(r_T\oplus e_i\).

Fix \(i\). Let \(Z_T=1\) if \(P\) is correct on \(r_T\oplus e_i\), and \(Z=\sum_T Z_T\). By Claim 4.3 each point is uniform, so \(\mathbb{E}[Z_T]=s_x\ge\frac12+\frac\varepsilon2\) and \(\mathbb{E}[Z]\ge m(\frac12+\frac\varepsilon2)\). (If \(P\) is randomized, give it fresh coins on every call; nothing changes.) The \(Z_T\) are pairwise independent, so variances add: \(\mathrm{Var}[Z]\le m/4\).

The majority is wrong only if \(Z\le m/2\), which forces \(Z\le\mathbb{E}[Z]-m\varepsilon/2\). By Chebyshev, $$\Pr[z_i\ne x_i]\le\Pr\big[|Z-\mathbb{E}Z|\ge \tfrac{m\varepsilon}2\big]\le\frac{m/4}{(m\varepsilon/2)^2}=\frac{1}{m\varepsilon^2}\le\frac1{2n},$$ using \(m\ge 2n/\varepsilon^2\). A union bound over the \(n\) bits gives \(\Pr[z\ne x]\le n\cdot\frac1{2n}=\frac12\). ∎

4.6 Finishing the proof: explicit success probability

Inversion probability. For a random \(x\):

  • with probability \(\ge\varepsilon/2\), \(x\) is good (Claim 4.2);
  • given that, with probability \(\ge\frac12\), the correct-guess iteration outputs \(x\) (Claim 4.4), which passes the check \(f(z)=y\).

\(I\) might stop earlier at a different \(z\) with \(f(z)=y\), but that is also a correct inversion. So

$$\Pr_x\big[f(I(f(x)))=f(x)\big]\ \ge\ \frac\varepsilon2\cdot\frac12=\frac{\varepsilon}{4}\ \ge\ \frac{1}{4n^c}\quad\text{for infinitely many }n.$$

Why this is not negligible: \(\frac{1}{4n^c}\ge\frac1{n^{c+1}}\) for \(n\ge4\). So the inversion probability is at least \(1/n^{c+1}\) for infinitely many \(n\), while a negligible function must be below \(1/n^{c+1}\) for all large \(n\).

Efficiency. \(2^t\le 2(2n/\varepsilon^2+1)=O(n^{2c+1})\) guesses. Each makes \(n\cdot m=O(n^{2c+2})\) calls to \(P\) and one evaluation of \(f\). The total is polynomial.

So \(I\) is an efficient inverter with non-negligible success, contradicting the one-wayness of \(f\). ∎

For circuits: if \(P\) is a circuit, \(I\) is a circuit of polynomially larger size. HILL's stronger Prop. 4.2 shows the list of candidates has size \(O(1/\varepsilon^2)\) HILL Prop. 4.2, p.1376; this is the “list decoding of the Hadamard code” view V p.147.

5. Warm-up: one-way permutation ⇒ PRG

Theorem 5.1
Let \(f\) be a one-way permutation (a bijection on \(\bits^n\)). Then \(G(x,r)=(f(x),\,r,\,\langle x,r\rangle)\), from \(2n\) bits to \(2n+1\) bits, is a PRG. HILL Prop. 4.4, p.1376 Barak Thm. 1 V p.147
Proof.

Approach. Direct: show the PRG game is literally the two-experiment Goldreich–Levin game, then apply Lemma 3.2 and Theorem 4.1.

Assume. \(f\) is a one-way permutation, and \(A\) is any efficient adversary.

Recall. Theorem 4.1 (Goldreich–Levin). Lemma 3.2(b). A bijection maps a uniform input to a uniform output.

WTS: \(\mathrm{PRGadv}[A,G]\) is negligible for every efficient \(A\).

Let \(A\) be any efficient adversary in the PRG game (S1 Figure 2).
  • Experiment 0 gives \(A\) the string \(G(X,R)=(f(X),R,\langle X,R\rangle)\).
  • Experiment 1 gives \(A\) a uniform \((2n+1)\)-bit string. Key observation: since \(f\) is a bijection, \(f(X)\) is uniform on \(\bits^n\). So \((f(X),R,\beta)\) is exactly uniform on \(\bits^{2n+1}\), and Experiment 1 can equivalently give \(A\) the string \((f(X),R,\beta)\).

So \(\mathrm{PRGadv}[A,G]=\Pr[A(f(X),R,\langle X,R\rangle)=1]-\Pr[A(f(X),R,\beta)=1]\). This is precisely \(A\)'s advantage in the two-experiment form of Goldreich–Levin.

Advantage: by Lemma 3.2(b), \(A\) gives a predictor for \(\langle x,r\rangle\) with prediction advantage exactly \(\mathrm{PRGadv}[A,G]\).

Why this is negligible: by Theorem 4.1, every efficient predictor's prediction advantage is negligible. So \(\mathrm{PRGadv}[A,G]\) is negligible for every efficient \(A\). ∎

Then S1 Theorem 6.2 stretches \(G\) from 1 extra bit to any polynomial number. (If RSA is a one-way permutation, as is widely believed, this gives a concrete PRG BS §10.3.)

Why the proof needs a permutation. It used two facts HILL p.1377:

  1. \(f(X)\) is uniform, so it already looks random;
  2. \(f(x)\) determines \(x\), so no randomness is lost.

For a one-to-one but length-increasing \(f\), fact 2 still holds but fact 1 fails. HILL's example: if \(f(x)=(0,f'(x))\) for a one-way permutation \(f'\), then \(f\) is a one-to-one one-way function. But \(G\)'s output always starts with 0, and an adversary that checks the first bit has advantage \(1/2\) HILL p.1377. Sections 6–7 repair fact 1 by hashing.

6. Tools: collision probability, hashing, and the leftover hash lemma

6.1 Collision probability: measuring how “spread out” a distribution is

Definition 6.1
For a random variable \(Z\) and an independent copy \(Z'\), the collision probability is \(\mathrm{Col}(Z)=\Pr[Z=Z']=\sum_z\Pr[Z=z]^2\). Wichs Claim 1 V Def. 6.7, p.113
  • If \(Z\) is uniform on a set of size \(2^K\), then \(\mathrm{Col}(Z)=2^K\cdot 2^{-2K}=2^{-K}\). We'll say \(Z\) has “\(K\) bits of randomness”.
  • For independent copies, \(\mathrm{Col}(Z_1,\dots,Z_k)=\prod_i\mathrm{Col}(Z_i)\) (collide everywhere ⇔ collide in each coordinate) Claude.
  • HILL phrase “\(\mathrm{Col}(Z)\le 2^{-K}\)” as “Rényi entropy at least \(K\)” HILL Lemma 4.8, p.1378. We won't need that vocabulary.

6.2 Pairwise-independent hash functions

Definition 6.2
A family \(\mathcal H\) of functions \(\bits^N\to\bits^j\) is pairwise independent if, for a random \(h\in\mathcal H\) and every pair \(z\ne z'\), the pair \((h(z),h(z'))\) is uniform on \(\bits^{2j}\). HILL Def. 4.6, p.1377

Construction HILL Def. 4.7, p.1378: \(h_{M,v}(z)=Mz\oplus v\), where \(M\) is a uniform \(j\times N\) matrix over GF(2) and \(v\) is a uniform vector in \(\bits^j\). Describing \(h\) takes \(p=jN+j\) bits. (HILL append a 1 to \(z\) instead of adding \(v\); it's the same thing.)

Why it is pairwise independent.

Approach. Direct computation.

Assume. \(M\) is a uniform \(j\times N\) matrix and \(v\) a uniform vector, chosen independently, and \(z\ne z'\).

Recall. XOR-ing a uniform string onto an independent string gives a uniform string. A nonzero coordinate of \(z\oplus z'\) picks out a uniform column of \(M\).

WTS: \((h(z),h(z'))\) is uniform on \(\bits^{2j}\).

Claude Fix \(z\ne z'\). Then \(h(z)\oplus h(z')=M(z\oplus z')\). Since \(z\oplus z'\ne0\), some coordinate \(k\) of \(z\oplus z'\) is 1. Then \(M(z\oplus z')\) equals column \(k\) of \(M\) XOR-ed with the other columns used, so it is uniform. It is also independent of \(v\). And \(h(z)=Mz\oplus v\) is uniform given \(M\), because of \(v\). So \((h(z),\,h(z)\oplus h(z'))\) is uniform on \(\bits^{2j}\), and therefore so is \((h(z),h(z'))\). ∎

In our constructions, \(h\) is chosen at random as part of the seed and output in the clear. It's a public input, like \(r\) in Goldreich–Levin HILL p.1377–1378.

6.3 The leftover hash lemma

Lemma 6.3 (leftover hash lemma)
Let \(Z\) be a random variable on \(\bits^N\) with \(\mathrm{Col}(Z)\le 2^{-K}\). Let \(h\) be uniform from a pairwise-independent family \(\bits^N\to\bits^j\) with \(j=K-2e\). Then $$\Delta\big((h,\,h(Z)),\ (h,\,U_j)\big)\ \le\ 2^{-(e+1)}.$$ HILL Lemma 4.8, p.1378 (with proof) V Thm. 6.18, p.118 Wichs Thm. 1

In words: hashing \(K\) bits of randomness down to \(K-2e\) bits gives an output that is nearly uniform, even to an all-powerful adversary that also sees \(h\). Shaving off \(2e\) bits buys error \(2^{-(e+1)}\).

Proof.

Approach. Direct: write \(\Delta\) as an average over \(h\), bound each term's second moment using pairwise independence (where the collision probability appears), then return to first moments.

Assume. \(\mathrm{Col}(Z)\le2^{-K}\), and \(h\) is uniform from a pairwise-independent family \(\bits^N\to\bits^j\) with \(j=K-2e\).

Recall. The sum formula for \(\Delta\) (S1 §3.2). Pairwise independence (Definition 6.2). \((\mathbb{E}|W|)^2\le\mathbb{E}[W^2]\).

WTS: \(\Delta\big((h,h(Z)),(h,U_j)\big)\le2^{-(e+1)}\).

Following HILL p.1378–1379, with steps expanded.

Reduce to one \(h\) at a time. For a fixed \(h\) and \(a\in\bits^j\), let \(p_h(a)=\Pr_Z[h(Z)=a]\). Both distributions pick \(h\) the same way, so (by the sum formula for \(\Delta\), S1 §3.2) $$\Delta=\mathbb{E}_h\Big[\tfrac12\sum_a\big|p_h(a)-2^{-j}\big|\Big]=\tfrac12\sum_a \mathbb{E}_h\big|p_h(a)-2^{-j}\big|.$$

Bound the second moment. Fix \(a\). Write \(p_h(a)-2^{-j}=\mathbb{E}_Z[\,\mathbf 1\{h(Z)=a\}-2^{-j}\,]\). Squaring and using an independent copy \(Z'\): $$\mathbb{E}_h\big[(p_h(a)-2^{-j})^2\big]=\mathbb{E}_{Z,Z'}\Big[\mathbb{E}_h\big[(\mathbf 1\{h(Z)=a\}-2^{-j})(\mathbf 1\{h(Z')=a\}-2^{-j})\big]\Big].$$
  • If \(Z\ne Z'\): \(h(Z)\) and \(h(Z')\) are independent and uniform (pairwise independence). So the inner expectation is a product of two terms that are each \(2^{-j}-2^{-j}=0\).
  • If \(Z=Z'=z\): the inner expectation is \(\mathrm{Var}(\mathbf 1\{h(z)=a\})=2^{-j}(1-2^{-j})\le 2^{-j}\).
So \(\mathbb{E}_h[(p_h(a)-2^{-j})^2]\le\Pr[Z=Z']\cdot2^{-j}=\mathrm{Col}(Z)\,2^{-j}\le 2^{-K-j}\).

From second moment to first moment. For any random variable \(W\), \((\mathbb{E}|W|)^2\le\mathbb{E}[W^2]\), because the difference is \(\mathrm{Var}(|W|)\ge0\). So \(\mathbb{E}_h|p_h(a)-2^{-j}|\le 2^{-(K+j)/2}\).

Sum over \(a\). $$\Delta\le\tfrac12\cdot 2^j\cdot 2^{-(K+j)/2}=\tfrac12\cdot2^{-(K-j)/2}=\tfrac12\cdot 2^{-e}=2^{-(e+1)}.\ ∎$$

7. Main construction: one-to-one one-way function ⇒ PRG

7.1 Pseudoentropy: the 1-bit gap

Let \(f:\bits^n\to\bits^\ell\) be a one-to-one one-way function (\(\ell\ge n\)). Let \(X,R\) be uniform on \(\bits^n\) and \(\beta\) a uniform bit. Define

$$D=(f(X),\,R,\,\langle X,R\rangle)\qquad\text{and}\qquad E=(f(X),\,R,\,\beta),$$

both on \(\bits^{\ell+n+1}\). Three facts:

  1. \(D\) and \(E\) are computationally indistinguishable. This is the two-experiment form of Theorem 4.1.
  2. \(E\) has \(2n+1\) bits of randomness. \(f\) is one-to-one, so the triple \((f(x),r,\beta)\) determines \((x,r,\beta)\). So \(E\) is uniform on a set of exactly \(2^{2n+1}\) strings, and \(\mathrm{Col}(E)=2^{-(2n+1)}\).
  3. \(D\) has only \(2n\) bits of randomness. It's a function of the \(2n\) input bits.

So \(D\) looks like it has one more bit of randomness than it really has. HILL call \(g(x,r)=(f(x),r,\langle x,r\rangle)\) a pseudoentropy generator with pseudoentropy 1: its output is indistinguishable from a distribution with more randomness than its input HILL Prop. 4.5, p.1377; Defs. 3.7–3.8, p.1373. But \(D\) is not uniform (Section 5's example), so \(g\) is not yet a PRG.

7.2 The plan

  • The leftover hash lemma turns randomness into near-uniformity. Hashing \(E\) down to slightly fewer than \(2n+1\) bits would give a nearly uniform string. Since \(D\approx E\), hashing \(D\) should look nearly uniform too, and \(D\) only cost \(2n\) seed bits.
  • Problem: the lemma loses \(2e\) bits for error \(2^{-(e+1)}\). For negligible error we need \(e\) to grow (e.g. \(e=n\)), but one copy only gains 1 bit.
  • Fix: take \(k\) independent copies. The real randomness is \(2nk\), the apparent randomness is \((2n+1)k\), and the gap is \(k\) bits, which can exceed \(2e\).

This is HILL's construction from a pseudoentropy generator HILL §4.6, Construction 4.13, p.1380 Scribe §3.1.

7.3 The construction

Construction 7.1
Parameters: \(k=4n\) copies, \(e=n\), input length to the hash \(N=k(\ell+n+1)\), output length \(j=k(2n+1)-2e\). Let \(\mathcal H\) be the pairwise-independent family \(\bits^N\to\bits^j\) of §6.2, with description length \(p\). $$G(x_1,r_1,\dots,x_k,r_k,\,h)=\Big(h,\ h\big(g(x_1,r_1),\dots,g(x_k,r_k)\big)\Big),\qquad g(x,r)=(f(x),r,\langle x,r\rangle).$$
  • Seed length: \(2nk+p\).
  • Output length: \(p+j=p+2nk+k-2e=(\text{seed length})+(k-2e)=(\text{seed length})+2n\).
  • \(G\) is computable in polynomial time.
HILL Construction 4.13, p.1380 (general version). The parameters \(k=4n,\ e=n\) are a simplification for the one-to-one case: Claude, see the note after the proof.
Theorem 7.2
If \(f\) is a one-to-one one-way function, then \(G\) of Construction 7.1 is a PRG (with stretch \(2n\)). HILL Prop. 4.5 + Thm. 4.14, p.1377–1380
Proof.

Approach. Hybrid through one intermediate distribution: one computational step (a reduction to Goldreich–Levin over \(k\) copies) and one statistical step (the leftover hash lemma).

Assume. \(f\) is a one-to-one one-way function, and \(A\) is any efficient adversary against \(G\).

Recall. Theorem 4.1 (two-experiment form). S1 Theorem 6.1 (\(k\) copies). Lemma 6.3. Statistical ⇒ computational (S1 §3.3). The closure facts. \(\mathrm{Col}(E)=2^{-(2n+1)}\) (§7.1).

WTS: \(\mathrm{PRGadv}[A,G]\) is negligible for every efficient \(A\). (Stretch was checked in Construction 7.1.)

Let \(A\) be any efficient adversary. Let \(D_1,\dots,D_k\) be independent copies of \(D\), and \(E_1,\dots,E_k\) independent copies of \(E\). Consider three distributions on the output space \(\bits^{p+j}\):
distributionwhat it is
\(Q_0\)\((h,\ h(D_1,\dots,D_k))\)\(G\) on a uniform seed (Experiment 0)
\(Q_{\text{mid}}\)\((h,\ h(E_1,\dots,E_k))\)a hybrid
\(Q_1\)\((h,\ U_j)\)uniform on \(\bits^{p+j}\) (Experiment 1), since \(h\)'s description is uniform bits

Write \(q_\bullet=\Pr[A(Q_\bullet)=1]\). Then \(\mathrm{PRGadv}[A,G]=|q_0-q_1|\le|q_0-q_{\text{mid}}|+|q_{\text{mid}}-q_1|\).

Second term (statistical). \(Z=(E_1,\dots,E_k)\) has \(\mathrm{Col}(Z)=\mathrm{Col}(E)^k=2^{-k(2n+1)}\). Apply Lemma 6.3 with \(K=k(2n+1)\) and \(j=K-2e\): \(\Delta(Q_{\text{mid}},Q_1)\le 2^{-(e+1)}=2^{-(n+1)}\). By S1's statistical ⇒ computational theorem (§3.3), \(|q_{\text{mid}}-q_1|\le 2^{-(n+1)}\).

First term (computational). Build \(B(z_1,\dots,z_k)\): sample a random \(h\) itself, and output \(A(h,h(z_1,\dots,z_k))\).

  • On \(k\) copies of \(D\), \(B\) outputs 1 with probability \(q_0\).
  • On \(k\) copies of \(E\), \(B\) outputs 1 with probability \(q_{\text{mid}}\).

So \(B\) distinguishes \(D^k\) from \(E^k\) with advantage \(|q_0-q_{\text{mid}}|\). By the multiple-samples hybrid argument (S1 Theorem 6.1, Figure 4), there is an efficient \(B'\) distinguishing a single \(D\) from \(E\) with \(|q_0-q_{\text{mid}}|\le k\cdot\mathrm{Distadv}[B',D,E]\). (For uniform adversaries this needs \(D\) and \(E\) to be efficiently samplable HILL Prop. 4.12, p.1380 V p.149. They are: sample \(x,r,\beta\) and compute \(f\).)

Advantage: $$\mathrm{PRGadv}[A,G]\ \le\ 4n\cdot\mathrm{Distadv}[B',D,E]\ +\ 2^{-(n+1)}.$$

Why this is negligible:

  • \(\mathrm{Distadv}[B',D,E]\) is negligible in \(n\) by Theorem 4.1 (two-experiment form).
  • \(4n\) times a negligible function is negligible (closure, S1 §2.1).
  • \(2^{-(n+1)}\) is negligible.
  • A sum of two negligible functions is negligible BS Fact 2.6.

The security parameter of \(G\) is its seed length \(2nk+p\), a polynomial in \(n\). Polynomially related parameters give the same notion of negligible (S1 §2.2). So \(G\) is a secure PRG. ∎

Note on parameters Claude. HILL's general Construction 4.13 takes \(k=\lceil(2m+1)/s\rceil^3\) copies and shaves off \(2mk^{2/3}\) bits. That's because a general pseudoentropy generator only promises Shannon entropy, and converting Shannon entropy to collision probability needs many copies HILL Prop. 4.9 & Cor. 4.10, p.1379. In the one-to-one case, \(E\) is uniform on its support, so its collision probability is known exactly. That lets us use the simpler \(k=4n\), \(e=n\). Please double-check this simplification when you review.

Finally, S1 Theorem 6.2 can stretch the output further if needed.

8. The theorem assembled, and the link back to derandomization

Theorem 8.1 (HILL; the part proved on these pages)
  1. If a PRG exists, then a one-way function exists (Theorem 2.1).
  2. If a one-to-one one-way function exists, then a PRG exists, with any polynomial stretch (Theorem 7.2 + S1 Theorem 6.2).
  3. (Stated only.) If any one-way function exists, then a PRG exists HILL Thm. 6.3, p.1385.
Corollary 8.2
If a one-to-one one-way function secure against polynomial-size circuits exists, then \(\BPP\subseteq\SUBEXP\).
Proof.

Approach. Direct: check that every reduction keeps circuit adversaries as circuits, then chain the theorems.

Assume. \(f\) is a one-to-one one-way function secure against polynomial-size circuits.

Recall. Theorem 7.2, and S1 Theorem 8.6.

WTS: \(\BPP\subseteq\SUBEXP\).

Every reduction on this page turns a circuit adversary into a circuit adversary:
  • the Goldreich–Levin inverter (§4.6);
  • the hybrid over copies (S1 Theorem 6.1, nonuniform version);
  • the hashing step, which is statistical.
So Theorem 7.2 gives a PRG secure against polynomial-size circuits, and S1 Theorem 8.6 finishes. ∎

This completes the cryptographic route of S1 §8.7: one-to-one one-way function ⇒ cryptographic PRG ⇒ derandomization PRG ⇒ \(\BPP\subseteq\SUBEXP\).

9. Beyond one-to-one (stated, not proved)

What goes wrong for a general \(f\). If an output of \(f\) has many preimages, then \(f(X)\) loses information about \(X\). HILL's example is a function where every output has \(2^{n/4}\) preimages HILL §5.1, p.1383.

  • \(D=(f(X),R,\langle X,R\rangle)\) then has only about \(\frac{7n}4+1\) bits of randomness instead of \(2n\).
  • Worse, \(\langle X,R\rangle\) is now genuinely close to random given \((f(X),R)\), since there are many possible \(x\)'s. So it is hidden for statistical reasons, and there is no gap between apparent and real randomness to exploit.

Regular one-way functions (every output has the same, known number \(2^{d}\) of preimages) HILL Construction 5.1, Lemma 5.2, Thm. 5.5, p.1383–1384:

  • Append about \(d\) bits of a hash of \(x\): \(f'(x,h)=(f(x),\ h(x)_{1..d+2},\ h)\).
  • This “recaptures” the lost randomness, making \(f'\) almost one-to-one, and it stays one-way.
  • Then the machinery of §7 applies, with extra care because the distributions are no longer exactly uniform on their supports.

General one-way functions HILL §6, Thms. 6.2–6.3, p.1384–1385:

  • The number of preimages varies from output to output and can't be computed, so the construction guesses it.
  • That yields only a false-entropy generator: output that looks more random than it really is, but not more random than the input HILL Def. 3.9, p.1374.
  • More copies and hashing turn that into a pseudoentropy generator (§4.7), then a PRG (§4.6, our §7).
  • The guessed parameter is finally removed by trying all values (§4.8).
  • The background needed beyond these pages is Shannon entropy and how it concentrates over many copies HILL Prop. 4.9, p.1379.

A 9-page treatment of the general case, for circuit adversaries, is in Scribe §2–3. HILL themselves call §6 “the most technically challenging” part of the paper HILL p.1367.
