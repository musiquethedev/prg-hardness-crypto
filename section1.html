Section 1: PRG and Cryptography Introduction

In the course, we gave a very high-level sketch explaining why the existence of something called a “Pseudorandom Generator” would lead to the derandomization result \(\Pclass=\BPP\). The sketch left out many lower-level details and even omitted explaining how such a proof would be formalized in the first place. What does it mean for bits to “look random” to a poly-time TM? to all poly-time TMs?

In this section, we introduce foundational ideas in cryptography to formalize this “computational indistinguishability” as well as proof techniques that will allow us to reason about them. We then attempt to prove the result from lecture—no matter whether we actually manage to show \(\Pclass=\BPP\) or some different result, we'll have all the foundations needed for the next section.

1. Recap of UCT Content

Derandomization, in general, is the process of taking algorithms that use random bits and creating equivalent algorithms that don't. The simplest derandomization result is \(\BPP\subseteq\EXP\): we can run any \(\BPP\) algorithm on all possible random strings in \(\EXP\) time, thus removing its need to use randomness at all. This relies on the fact that if a random algorithm uses at most \(k\) random bits, there are at most \(2^k\) sequences of random strings it can be run on.

The number of random bits used by any \(\BPP\) algorithm is bounded by \(\poly(n)\). But what if it was bounded by \(O(\log n)\) instead? Then we could run such a \(\BPP\) algorithm on all \(2^{O(\log n)}\) random strings in \(\poly(n)\) time; the resulting derandomized algorithm would be in \(\Pclass\), ending up with \(\Pclass=\BPP\). This would be a huge theoretical result, with huge implications across the entire spectrum of theoretical computer science. Therefore, in order to prove \(\Pclass=\BPP\), it suffices to show that every \(\BPP\)-time TM can be converted into a poly-time probabilistic TM that uses \(O(\log n)\) bits.

In lecture, this is where we introduced the Pseudorandom Generator (PRG), a TM \(G\) that turns \(O(\log n)\) truly random seed bits into \(\poly(n)\) bits that “look random” to all poly-time machines. The new machine is \(M'(x,s) = M(x, G(s))\). The deterministic simulation then works like this:

  • Run \(M'(x,s)\) for every seed \(s\). There are only \(2^{O(\log n)} = \poly(n)\) of them.
  • Output the majority answer.

The answers need not agree across seeds. Even with truly random bits, \(M\) is wrong on up to \(1/3\) of random strings. What “fooling \(M\)” guarantees is that the fraction of seeds giving the right answer is close to the fraction of truly random strings giving the right answer (at least \(2/3\)). So more than half the seeds are right, and the majority vote is correct. If the fraction under \(G\) were far from what random bits give, then “run \(M(x,\cdot)\) and check the answer” would itself be a test that tells \(G\)'s output apart from random.

As mentioned in lecture, we “believe” such PRGs exist because hard functions can be turned into pseudorandomness (“Hardness ⟹ Derandomization”), but we give no definitions or proofs. “Randomness is in the eye of the beholder”, as we say.

In this section, we will systematically go through each element this proof omits or glazes over and flesh it out at a low-level, introducing key proof techniques used in cryptography along the way. The elements that the proof misses are as follows:

  1. What exactly does “looks random to poly-time machines” mean?
  2. What exactly is a “hard function”? (we'll actually cover this in Section 2, with one-way functions)
  3. What proof techniques let us use these definitions?
  4. What exactly is the derandomization process?

2. Background: Negligibility and the Adversary's Computational Model

Adversarial Thinking

As stated in lecture, we're interested in functions (we'll call them PRGs) that turn \(O(\log n)\) truly random bits into \(\poly(n)\) bits that “look random” to poly-time machines. This is inherently an adversarial relationship: the PRGs that generate the bits versus the poly-time machines that try to distinguish them from truly random bits. We'll put ourselves in the shoes of the PRG, while the poly-time machine doing the distinguishing work will be the adversary.

One can always consider, as a baseline, a poly-time machine adversary that just randomly guesses whether it's looking at truly random bits or PRG output. Thus, we need to consider how much better a given adversary performs compared to this baseline: that will be its “advantage”.

Negligible functions

We say that polynomially-bounded functions are “reasonably large”, while exponentially-bounded functions are “unreasonably large”, in terms of computation bounds. Likewise, we might want to say that functions of the form \(1/\poly(n)\) are “reasonably small”. Anything smaller than \(1/\poly(n)\) would thus be “unreasonably small”; in other words, negligibly small.

Definition (negligible), formally
\(\varepsilon:\mathbb{Z}_{\ge 1}\to\mathbb{R}\) is negligible if for every \(c\gt 0\) there is an \(n_0\) with \(|\varepsilon(n)| \lt 1/n^c\) for all \(n\ge n_0\). Equivalently, \(\lim_{n\to\infty} \varepsilon(n)\,n^c = 0\) for every \(c\gt 0\). A function \(s\) is super-poly if \(1/s\) is negligible.
Closure facts
If \(\varepsilon,\varepsilon'\) are negligible and \(p\) is polynomially bounded, then \(\varepsilon+\varepsilon'\) and \(p\cdot\varepsilon\) are negligible.
Proof of the second fact. Say \(p(n)\le n^k\) for large \(n\). Given \(c\), apply negligibility with \(c+k\): for large \(n\), \(\varepsilon(n)\lt 1/n^{c+k}\), so \(p(n)\varepsilon(n)\lt n^k/n^{c+k}=1/n^c\). ∎

On the other hand, if a function is “non-negligible”, there is a constant \(c\) with \(\varepsilon(n)\ge 1/n^c\) for infinitely many \(n\) (not necessarily for all \(n\); think about how big O only needs to hold after the \(n_0\) boundary).

Adversaries and their Computational Models

In lecture, we just talk about poly-time TMs. However, we're actually going to expand that definition a little bit: our adversaries will instead be (potentially nonuniform) polynomial-sized circuit families, corresponding to the class \(\Ppoly\).

By fooling these nonuniform machines, we'll actually be proving a stronger result than if we fooled \(\Pclass\)-time machines or \(\BPP\)-time machines or something similar. However, there's a really good reason we want to make this change: pretty much all of our proofs will be by contrapositive, meaning the extra power afforded by nonuniformity will be a huge boon to making our proofs cleaner and more natural.

If we go the other route, we consider adversaries that have poly-time TM powers. This may come up briefly in later proofs; I'll refer to this as the “uniform” route (corresponding to uniform \(\Ppoly=\Pclass\)).

3. Attack Games and Computational Indistinguishability

Attack Games

Let's actually formally define what we mean by adversaries and “fooling”. Every definition in derandomization and in security can be described as an attack game between two parties:

  • a challenger, who follows a fixed, simple procedure (corresponds to the “PRG” in the lecture content), and sends some data \(x\) to the adversary.
  • an adversary \(A\), who may use any strategy to distinguish something about the challenger from the data \(x\) that they sent (corresponds to the “poly time TMs” in the lecture content)

Notice the challenger is allowed to change up their strategy depending on the experiment, while the adversary's chosen algorithm must work the same way across both experiments.

More formally, the game will play across two experiments, labelled 0 and 1. The challenger will choose some data \(x\) from some distribution \(P_b\), where \(b\) represents which experiment we are in. The adversary \(A\) receives \(x\) and runs their algorithm on \(x\), and must output a \(\hat b\), their guess for which experiment we are in (equivalently, whether \(x\) was drawn from \(P_0\) or \(P_1\)).

Let \(W_b\) be the event that \(A\) outputs 1 in experiment \(b\). So \(W_1\) occurs when the experiment is 1 and \(A\) correctly distinguishes that, while \(W_0\) occurs when the experiment is 0 and \(A\) incorrectly thinks it's experiment 1. We can then have the following advantage.

Attack Game (distinguishing \(P_0\) from \(P_1\))
In Experiment \(b\in\{0,1\}\), the challenger samples \(x\leftarrow P_b\) and sends \(x\) to \(A\). Then \(A\) outputs \(\hat b\in\{0,1\}\). $$\mathrm{Distadv}[A,P_0,P_1] := \big|\Pr[W_0]-\Pr[W_1]\big|.$$

This is distinct from \(A\)'s success probability: consider an adversary that always outputs 1: \(\Pr[W_0]=\Pr[W_1]=1\), so their advantage is 0. This makes sense because they have no “intuitive” advantage; they don't know anything about the challenger.

Statistical Distance: the Bounds of an All-Powerful Adversary

Notice that we still haven't fixed the adversaries to be poly-time bounded or to be restricted to a particular computational model. That means we can consider the following question: if an all-powerful adversary played the attack game as before, what's the best possible advantage they could achieve? Our bound will be based off the following observation: if the data \(x\) that the challenger sent is equally likely in \(P_0\) and \(P_1\), then no adversary can reliably choose the correct \(P_b\); only if \(x\) is more likely in one than the other can any adversary extract any advantage.

Assume \(A\) is running a deterministic algorithm (we'll show that randomness here is not very important). Then \(A\) essentially boils down to outputting 1 if and only if \(x\) falls into some set \(R'\) (the “language” of \(A\)'s algorithm), which is a subset of \(R\), the codomain of the challenger's \(x\) generation function. Then \(A\)'s advantage is exactly:

$$\Pr[W_0]-\Pr[W_1] = P_0[R']-P_1[R'] = \sum_{r\in R'}\big(P_0(r)-P_1(r)\big).$$

To choose an \(R'\) that will maximize this advantage value, we'll fill \(R'\) with every \(r\) that is more likely under \(P_0\) than \(P_1\). This means its advantage becomes:

$$\sum_{r:\,P_0(r)\gt P_1(r)}\big(P_0(r)-P_1(r)\big) \;=\; \tfrac12\sum_{r\in R}\big|P_0(r)-P_1(r)\big|.$$

This holds because the area of \(P_0\) that exceeds \(P_1\) is exactly the same as the area of \(P_1\) that exceeds \(P_0\); they're both distributions, so they both must sum to 1. A randomized algorithm by the adversary would just average several deterministic ones, meaning it wouldn't do any better.

Definition (statistical distance)
$$\Delta(P_0,P_1) := \tfrac12\sum_{r\in R}|P_0(r)-P_1(r)| \;=\; \max_{R'\subseteq R}\big|P_0[R']-P_1[R']\big|.$$ By the argument above, this is exactly the best advantage any adversary, efficient or not, can achieve in the distinguishing game.

Seeds and Secrets

So far, we've been considering the challenger as simply drawing \(x\) from probability distributions \(P_0\) and \(P_1\). How does this relate to the PRGs the lecture mentioned, which use the log-sized random bits as a seed? How does this relate to cryptographic algorithms that use shared secrets?

In the secret view, the challenger samples a secret uniformly, say \(s\in\bits^n\), and computes what it sends from \(s\). The adversary only ever sees the output, so all that matters to it is the probability of each possible output. That output distribution is \(P_0\) or \(P_1\).

A single pair \(P_0,P_1\) on a single finite set gives each adversary just one number as its advantage. So \(P_0\) and \(P_1\) are really sequences: for each \(n\), a pair \(P_0^{(n)},P_1^{(n)}\) on a set \(R_n\), such as \(\bits^{L(n)}\). In the secret view, \(n\) is exactly the secret length you sample for that member of the family. The adversary is a circuit family \(\{A_n\}\), and \(A_n\) plays against the \(n\)-th pair. This means that the advantage of \(A\) now becomes a function of \(n\).

Computational Indistinguishability

Now restrict the adversaries to efficient algorithms (poly-sized circuits).

Definition (computational indistinguishability)
\(P_0\) and \(P_1\) are computationally indistinguishable if \(\mathrm{Distadv}[A,P_0,P_1]\) is negligible for every efficient adversary \(A\).
Theorem (statistical ⇒ computational)
For every adversary \(A\), \(\mathrm{Distadv}[A,P_0,P_1]\le\Delta(P_0,P_1)\). So if \(\Delta\) is negligible, \(P_0\) and \(P_1\) are computationally indistinguishable.
Proof. \(\Delta\) is the best advantage over all adversaries (see above). Efficient adversaries are some of those, so none of them can beat it. ∎

4. Pseudorandom Generators (PRGs)

PRG Definition

A PRG is an efficient deterministic algorithm \(G:\bits^\ell\to\bits^L\) with \(L\gt\ell\). The security of a PRG will be defined by the advantage of an attack game, our first of many attack games.

The PRG attack game is the attack game of Section 3 with a specific pair of distributions. In Experiment 0, the challenger picks a uniformly random seed \(s\in\bits^\ell\) and sends \(x=G(s)\); so \(P_0\) is the distribution of \(G(s)\) over a uniform seed. In Experiment 1, the challenger sends a uniformly random \(x\in\bits^L\); so \(P_1\) is uniform on \(\bits^L\). The adversary sees only \(x\) and outputs its guess \(\hat b\).

Definition (secure PRG)
\(\mathrm{PRGadv}[A,G] := |\Pr[W_0]-\Pr[W_1]|\) in the PRG attack game. \(G\) is secure if \(\mathrm{PRGadv}[A,G]\) is negligible for every efficient \(A\).

Equivalently, we can say that a PRG \(G\) is secure if \(G(\bits^\ell)\) is computationally indistinguishable from \(\bits^L\). From now on, we'll call (the uniform distribution on) \(\bits^k\) by the symbol \(U_k\) for simplicity.

Note: the definition only requires that the PRG's output size be \(L\ge\ell+1\), one bit longer than its input size. We'll show later that this one bit of length increase is sufficient to create polynomially-long PRG outputs.

Other possible definitions

Here are some other ways we could've tried to define PRGs and why they are not smart.

  1. “\(G\)'s output should be distributed (almost) uniformly.” Impossible. \(G(U_\ell)\) has statistical distance at least \(1/2\) from uniform: it can take at most \(2^\ell\) of the \(2^L\) possible values.
  2. “\(G\)'s output should pass a standard list of statistical tests” (balanced 0s and 1s, balanced pairs, χ², …). Not enough. There are generators that pass all such standard tests yet are completely predictable: from a prefix of the output you can compute the rest. A fixed list of tests says nothing about the test an adversary designs specifically against \(G\).

Our definition sits between these two. It quantifies over every test, like (1), but only efficient ones, which makes it achievable.

5. Security Reductions

Definition

Almost every theorem in this area has the form “if primitive \(P\) is secure, then construction \(C\) is secure.” It is proved by reduction, usually in the contrapositive: given any efficient adversary \(A\) that breaks \(C\), build an efficient adversary \(B\) that breaks \(P\). Usually \(B\) runs \(A\) as a subroutine and plays the challenger for \(A\). This is similar to computational complexity reductions, which use one function as a subroutine for another to show hardness implications: security reductions equivalently show security implications.

Figure 1. A reduction. \(B\) attacks primitive \(P\) by running \(A\) (which attacks construction \(C\)) on a challenge built from \(P\)'s challenge \(z\). As long as what \(A\) sees in each of \(B\)'s experiments is a correctly distributed \(C\)-challenge, \(B\)'s advantage can be computed from \(A\)'s.

Here is the general template for a security reduction:

  1. Assume an attacker. Suppose an efficient \(A\) has non-negligible advantage \(\varepsilon\) against \(C\). We know nothing else about \(A\), so we use it as a black box.
  2. Build \(B\) around \(A\). \(B\) takes \(P\)'s challenge, turns it into a challenge for \(A\) (playing \(A\)'s challenger), runs \(A\), and uses \(A\)'s answer as its own guess.
  3. Check what \(A\) sees. In each of \(B\)'s experiments, \(A\) must get a correctly distributed challenge (or one it provably can't do well on), or \(\varepsilon\) says nothing.
  4. Compute \(B\)'s advantage as an explicit formula in \(\varepsilon\).
  5. Show it is non-negligible. Then \(B\) breaks \(P\), contradicting \(P\)'s security.

Example: PRGs exist ⟹ \(\Pclass\ne\NP\)

While this proof won't exactly use another adversary as a subroutine, and so doesn't exactly follow the steps outlined above, the general structure is the same.

Additionally, I know that when defining our terms, we said that adversaries are poly-bounded circuits. For this proof, pretend they also could be poly-time TMs (as in lecture). That allows us to achieve the much more auraful result of \(\Pclass\subsetneq\NP\) rather than the mundane \(\NP\not\subseteq\Ppoly\).

Theorem 5.1 (PRGs ⇒ \(\Pclass\ne\NP\))
If a PRG exists that is secure against poly-time adversaries, then \(\Pclass\ne\NP\).
Proof. Suppose \(\Pclass=\NP\). Let \(L=\{y:\ y=G(s)\text{ for some } s\}\), the set of strings \(G\) can output. \(L\in\NP\): the seed \(s\) is a certificate, checked by running the algorithm for \(G\). (This is where we use that \(G\) is uniform.) Since \(\Pclass=\NP\), there is a poly-time TM \(D\) deciding \(L\).

Adversary \(B(r)\): output 1 iff \(D(r)\) accepts. In words, “say pseudorandom iff \(r\) is something \(G\) could have produced.” \(B\) is a poly-time TM, so it is an efficient adversary.

  • Experiment 0 (\(r=G(s)\), uniform seed \(s\)): \(r\in L\) always, so \(\Pr[W_0]=1\).
  • Experiment 1 (\(r\) uniform in \(\bits^\ell\)): \(B\) outputs 1 only if \(r\in L\), which only occurs if \(r\) happens to appear in \(G\)'s image by chance. Since \(G\) has only \(2^n\) seeds, \(\Pr[W_1]\le 2^n/2^\ell\le 1/2\).

Advantage: \(\mathrm{PRGadv}[B,G]=\Pr[W_0]-\Pr[W_1]=1-\frac{|\mathrm{Im}(G)|}{2^\ell}\ge 1-2^{n-\ell}\ge\frac12\) for every \(n\), which is clearly non-negligible with respect to \(n\). ∎

Replacing \(D\) with a poly-size nonuniform circuit family instead gives \(\NP\not\subseteq\Ppoly\), by the same logic.

This is a bit of a barrier to proving PRGs exist outright. I'm sure it's nothing 5 trillion claudes couldn't solve in the next 3 weeks.

6. The Hybrid Argument Lemma

Definition

Often the differences between the two experiments we want to compare, the fully pseudorandom experiment and the fully random experiment, differ in many places at once. A hybrid argument walks from one to the other with small, intermediary experiments. Each step makes a small change to the construction whose effect on the advantage can be quantified. In the end, the difference between the two important experiments (the advantage) can be bounded in terms of the intermediate steps using the triangle inequality.

We'll define this hybrid argument in general, and then use it to prove two useful lemmas: the first will show that independent repeats of computationally indistinguishable distributions remain indistinguishable, and the second will show that a PRG can be manipulated into larger PRGs while retaining its security.

Toy example

Let \(G:\bits^\ell\to\bits^L\) be a secure PRG, and let \(G'(s_1,s_2)=(G(s_1),G(s_2))\). Is \(G'\) secure? Take any efficient adversary \(A\) against \(G'\) and look at three games, changing one block at a time:

Gameblock 1block 2\(p_i=\Pr[A\text{ outputs }1]\)
Game 0 (real \(G'\))\(G(s_1)\)\(G(s_2)\)\(p_0\)
Game 1uniform\(G(s_2)\)\(p_1\)
Game 2 (uniform)uniformuniform\(p_2\)

\(\mathrm{PRGadv}[A,G']=|p_0-p_2|\le|p_0-p_1|+|p_1-p_2|\) (triangle inequality). Each term on the right is the advantage of an adversary against one copy of \(G\):

  • \(B_1(z)\): put the challenge \(z\) in block 1, put \(G(s_2)\) for a fresh seed in block 2, and run \(A\). If \(z=G(s)\) this is Game 0; if \(z\) is uniform it's Game 1. So \(\mathrm{PRGadv}[B_1,G]=|p_0-p_1|\).
  • \(B_2(z)\): put a uniform string in block 1 and \(z\) in block 2. This gives Game 1 vs. Game 2, so \(\mathrm{PRGadv}[B_2,G]=|p_1-p_2|\).

Both terms are negligible because \(G\) is secure, so their sum is negligible and \(G'\) is secure. That's the whole idea. The general version just has more games.

Hybrid Lemma (generalized)

Hybrid Lemma
Let \(X,Y\) be distributions and \(H_0,H_1,\dots,H_k\) a chain of distributions. Suppose that for each step \(i\) there is an efficient (possibly randomized) procedure \(T_i\) such that $$T_i(X)\ \text{is distributed as}\ H_{i-1}\qquad\text{and}\qquad T_i(Y)\ \text{is distributed as}\ H_i .$$ Then for every efficient adversary \(A\) there is an efficient adversary \(B\) with $$\big|\Pr[A(H_0)=1]-\Pr[A(H_k)=1]\big|\ \le\ k\cdot\big|\Pr[B(X)=1]-\Pr[B(Y)=1]\big|.$$

This is equivalent to saying “\(A\)'s advantage in distinguishing \(H_0\) from \(H_k\) is bounded by \(k\) times \(B\)'s advantage in distinguishing \(X\) from \(Y\)”.

Proof.

Let \(p_i=\Pr[A(H_i)=1]\), and assume \(p_0\ge p_k\) (otherwise flip \(A\)'s output). The sum telescopes: $$p_0-p_k=\sum_{i=1}^{k}\big(p_{i-1}-p_i\big).$$ A sum of \(k\) terms is at most \(k\) times its largest term, so some step \(i^*\) has \(p_{i^*-1}-p_{i^*}\ge\frac1k(p_0-p_k)\).

Let \(B(z)=A(T_{i^*}(z))\), with \(i^*\) hard-coded. Since \(T_{i^*}(X)\sim H_{i^*-1}\) and \(T_{i^*}(Y)\sim H_{i^*}\):

  • \(\Pr[B(X)=1]=p_{i^*-1}\);
  • \(\Pr[B(Y)=1]=p_{i^*}\).

Advantage: \(\Pr[B(X)=1]-\Pr[B(Y)=1]=p_{i^*-1}-p_{i^*}\ge\frac1k(p_0-p_k)\). Rearranged, that is the inequality in the statement. \(B\) is efficient because \(A\) and \(T_{i^*}\) are. ∎

How to use it. Every hybrid proof on this site follows the same recipe:

  1. write down the chain \(H_0,\dots,H_k\);
  2. for each step, describe the procedure \(T_i\) that builds \(H_{i-1}\) from a sample of \(X\) and \(H_i\) from a sample of \(Y\);
  3. apply the lemma, and use the closure facts (Section 2) to see that \(k\) times a negligible advantage is still negligible.

The toy example, in the lemma's terms. Take \(k=2\), \(X=G(U_\ell)\) (one PRG output on a fresh seed) and \(Y=U_L\) (one uniform block). The chain is the three games:

  • \(H_0=(G(s_1),G(s_2))\) (Game 0), \(H_1=(\text{uniform},G(s_2))\) (Game 1), \(H_2=(\text{uniform},\text{uniform})\) (Game 2).
  • \(T_1(z)=(z,\,G(s_2))\) for a fresh seed \(s_2\): then \(T_1(X)\sim H_0\) and \(T_1(Y)\sim H_1\).
  • \(T_2(z)=(\text{uniform},\,z)\): then \(T_2(X)\sim H_1\) and \(T_2(Y)\sim H_2\).

The lemma gives an efficient \(B\) with \(\mathrm{PRGadv}[A,G']\le 2\cdot\mathrm{PRGadv}[B,G]\). That \(B\) is \(B_1\) or \(B_2\) from the toy example, whichever step is larger.

Applications: Copies of indistinguishable distributions

Theorem 6.1
If \(X\) and \(Y\) are computationally indistinguishable and efficiently samplable, then so are \(k\) independent copies \(X^k\) and \(Y^k\), for any polynomial \(k\). In particular, if \(G\) is a secure PRG, so is \(G'(s_1,\dots,s_k)=(G(s_1),\dots,G(s_k))\).

Figure 2. Hybrids for \(k=4\). Each step changes exactly one block, so an adversary that notices a step yields an adversary against a single copy of \(G\).. Here \(X=G(\text{fresh seed})\) and \(Y\) = uniform.

Proof.
  1. Chain: \(H_i=X^{k-i}Y^{i}\), i.e. the first \(k-i\) copies from \(X\) and the last \(i\) from \(Y\). So \(H_0=X^k\) and \(H_k=Y^k\).
  2. Step \(i\): \(H_{i-1}\) and \(H_i\) differ only in copy number \(k-i+1\). Procedure \(T_i(z)\): sample \(k-i\) fresh copies of \(X\) and \(i-1\) fresh copies of \(Y\), and output \((x_1,\dots,x_{k-i},\,z,\,y_{1},\dots,y_{i-1})\). Then \(T_i(X)\sim H_{i-1}\) and \(T_i(Y)\sim H_i\).
  3. Lemma: there is an efficient \(B\) with \(\big|\Pr[A(X^k)=1]-\Pr[A(Y^k)=1]\big|\le k\cdot\big|\Pr[B(X)=1]-\Pr[B(Y)=1]\big|\).

For the PRG statement, take \(X=G(U_\ell)\) and \(Y=U_L\): then \(X^k=G'(\text{uniform})\) and \(Y^k\) is uniform, so \(\mathrm{PRGadv}[A,G']\le k\cdot\mathrm{PRGadv}[B,G]\), which is negligible by the closure facts (Section 2). ∎

(Circuits don't even need samplability: by averaging, \(B\) can hard-code the best fixed values for the other copies. All distributions we use are samplable anyway.)

Applications: “Stretching” a PRG

Theorem 6.2
Let \(G:\bits^\ell\to\bits^{\ell+1}\) be a secure PRG, and write its output as \(G(s)=(r,s')\), where \(r\) is one bit and \(s'\) is \(\ell\) bits. For a polynomial \(k\), define \(G'(s)\): set \(s_0=s\); for \(i=1,\dots,k\), set \((r_i,s_i)=G(s_{i-1})\); output \((r_1,\dots,r_k,s_k)\). Then \(G':\bits^\ell\to\bits^{\ell+k}\) is a secure PRG.
Proof.

\(G'\) runs \(G\) \(k\) times, feeding each new seed back in. For example, with \(k=3\): \((r_1,s_1)=G(s_0)\), \((r_2,s_2)=G(s_1)\), \((r_3,s_3)=G(s_2)\), output \(r_1r_2r_3s_3\).

Chain. In \(H_j\), the first \(j\) bits \(r_1,\dots,r_j\) and the seed \(s_j\) are uniform, and the rest is computed honestly from \(s_j\). For \(k=3\) (“u” = fresh uniform, “G” = computed honestly):

\(r_1\)\(r_2\)\(r_3\)\(s_3\)
\(H_0\) (\(s_0\) uniform)GGGG
\(H_1\) (\(r_1,s_1\) uniform)uGGG
\(H_2\) (\(r_1,r_2,s_2\) uniform)uuGG
\(H_3\)uuuu

So \(H_0=G'(\text{uniform seed})\) and \(H_k\) is uniform. Consecutive hybrids differ in exactly one call of \(G\): in \(H_{j-1}\), \(s_{j-1}\) is uniform and \((r_j,s_j)=G(s_{j-1})\); in \(H_j\), \((r_j,s_j)\) is uniform. Everything after that is computed the same way from \(s_j\).

Step \(j\). Procedure \(T_j(z)\), for \(z=(r,s)\): pick \(r_1,\dots,r_{j-1}\) uniformly, set \((r_j,s_j)=z\), compute the rest honestly, and output \(r_1\cdots r_k\,s_k\). If \(z=G(\text{uniform seed})\), the output is distributed as \(H_{j-1}\); if \(z\) is uniform, it is distributed as \(H_j\). \(T_j\) calls \(G\) at most \(k\) times, so it is efficient.

Lemma, with \(X=G(U_\ell)\) and \(Y=U_{\ell+1}\): there is an efficient \(B\) with \(\mathrm{PRGadv}[A,G']\le k\cdot\mathrm{PRGadv}[B,G]\), which is negligible by the closure facts since \(k\) is polynomial. (\(B\) hard-codes the best step \(j^*\), which may be different for each \(n\); that is fine because adversaries are circuit families.) ∎

Why only polynomially many rounds? The number of rounds \(k\) has to be polynomial for two reasons. \(G'\) must run in polynomial time, and it calls \(G\) \(k\) times. And the bound \(k\cdot\mathrm{PRGadv}[B,G]\) is only guaranteed to be negligible when \(k\) is polynomial (closure facts). With superpolynomially many rounds, neither holds.

This is the result that justifies why our PRG definition only needs the output size to be one bit bigger than the input; we can just use this method to enlarge it.

7. From PRGs to Derandomization: is the Lecture Proof Fixable Now?

The goal

Recall the lecture's plan from Section 1. To show \(\BPP=\Pclass\), take a \(\BPP\) machine \(M\) (poly-time, error \(\le 1/3\)) and a generator \(G\) that stretches an \(O(\log n)\)-bit seed into the random bits \(M\) needs. Run \(M(x,G(s))\) for every seed \(s\) and take the majority. Two things have to hold:

  1. \(G\) has to be computable in polynomial time, and its seed has to be \(O(\log n)\) bits, so there are only polynomially many seeds.
  2. \(G\)'s output has to be “random enough” that the majority answer is still correct.

The natural first idea is to use the PRGs we defined in Section 4.

First attempt: Using Our PRG Definition

Fact 7.1: a cryptographic PRG (a PRG following our definitions) cannot have an \(O(\log m)\) seed (equivalently, its seed space must be super-poly)
Proof. Suppose \(G:\bits^d\to\bits^m\) with \(d \le c\log m\). Adversary \(A(r)\): try every seed \(s\in\bits^d\), and output 1 if some \(G(s)=r\). This is the same image test as in Theorem 5.1.
  • \(\Pr[W_0]=1\).
  • \(\Pr[W_1]\le 2^{d-m}\le 1/2\).
  • \(A\) runs in time \(2^d\cdot\mathrm{time}(G)\le m^c\cdot\poly(m)\), which is polynomial.

Advantage: \(\mathrm{PRGadv}[A,G]=1-\frac{|\mathrm{Im}(G)|}{2^m}\ge 1-2^{d-m}\ge\frac12\). ∎

Importantly, this means that the construction from lecture, a PRG that takes a logarithmic seed, runs in polynomial time, and fools poly-time TMs is impossible. An adversary that enumerates all seeds can still run in polynomial time; just a larger polynomial time than the PRG itself. This means a cryptographic PRG, like the ones we've defined, won't work for this derandomization proof.

The fix: a subtly different PRG definition

The cryptographic PRG requirement of fooling all poly-time TMs may be a bit overkill here. Based on what the simulation strategy actually requires, it needs one \(\BPP\) machine \(M\) and one input \(x\) to fool one single test, “run \(M(x;\cdot)\)” (here \(M(x;r)\) means running \(M\) on input \(x\) with random bits \(r\), and the \(\cdot\) is the slot for the random bits). With \(x\) hard-coded, that test is a circuit of some fixed polynomial size \(m=n^c\). \(M\)'s error also just needs to be below one-half (to be in \(\BPP\)), so a constant advantage bound like \(1/8\) is enough. This gives a PRG game with a restricted set of adversaries:

Definition 7.2 (\((t,\varepsilon)\) PRG; derandomization PRG)
\(G:\bits^d\to\bits^m\) (with \(d\lt m\)) is a \((t,\varepsilon)\) PRG if every circuit of size at most \(t\) has \(\mathrm{PRGadv}\le\varepsilon\) against \(G\).
A derandomization PRG is a family of \((m,1/8)\) PRGs \(G_m:\bits^{d(m)}\to\bits^m\), one for each output length \(m\).

This is a special case of the cryptographic PRG requirement; the “PRG” need only fool a subset of the adversaries fooled by its cryptographic equivalent.

Main theorem: Derandomization PRGs give \(\BPP=\Pclass\)

Theorem 7.3
Suppose there is a derandomization PRG \(G_m:\bits^{d(m)}\to\bits^m\) with seed length \(d(m)=O(\log m)\) that is computable in time \(\poly(m)\). Then \(\BPP=\Pclass\).
Proof.

Setup. Let \(L\in\BPP\) be decided by a poly-time machine \(A(x;r)\) with error at most \(1/3\). By TM-to-circuit conversion, choose a constant \(c\) such that, on inputs of length \(n\), \(A\) uses at most \(n^c\) random bits and the test circuit \(T\) below has size at most \(n^c\). Pad \(A\)'s random string to exactly \(n^c\) bits, and set \(m=n^c\) and \(G=G_m\).

Claim. For every \(x\) of length \(n\), \(A(x;G(s))\) is correct for more than half of the seeds \(s\).

Proof of claim. Fix \(x\) and let \(T(r)=1\) iff \(A(x;r)\) gives the correct answer for \(x\). With \(x\) and the correct answer hard-coded, \(T\) is a circuit on \(m\) input bits with at most \(n^c=m\) gates, by the choice of \(c\) (circuit size counts AND/OR gates, not inputs or negations). So Definition 7.2 applies to \(T\).

  • \(\Pr[W_1]=\Pr_{r\text{ uniform}}[A(x;r)\text{ correct}]\ge 2/3\), since \(A\) is a \(\BPP\) machine.
  • \(\Pr[W_0]=\Pr_{s}[A(x;G(s))\text{ correct}]\), the fraction of good seeds.

\(G\) is an \((m,1/8)\) PRG, so \(|\Pr[W_0]-\Pr[W_1]|\le 1/8\). Hence the fraction of good seeds is \(\Pr[W_0]\ge 2/3-1/8=13/24\gt 1/2\). Note: \(x\) is hard-coded as advice inside \(T\). This is exactly why adversaries are circuits (Section 2).

Deterministic algorithm. On input \(x\), for every seed \(s\in\bits^{d(m)}\), compute \(G(s)\) and run \(A(x;G(s))\). Output the majority answer. By the claim, the majority is always correct.

Running time.

  • There are \(2^{d(m)}=2^{O(\log m)}=m^{O(1)}=n^{O(c)}\) seeds, which is polynomial.
  • Each seed costs \(\poly(m)=\poly(n)\) to compute \(G(s)\), plus \(\poly(n)\) to run \(A\).
  • Total: polynomial in \(n\). So \(L\in\Pclass\). ∎

Why did I explain it this way.

At this point you, the reader, might be shaking and crying in anguish, agony, despair, etc. Why did I go through all the work of defining cryptographic PRGs if this theorem doesn't even use them?

First off, we can adapt this proof to use cryptographic PRGs; if we do, the result will be showing \(\BPP\subseteq\SUBEXP\), which is the intersection of all \(O(2^{n^\varepsilon})\)-time solvable problems.

Secondly, cryptographic PRGs are the tool used for all the theorems left in the course. Stay tuned!
